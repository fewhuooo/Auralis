- 登录失效路由已按当前端收口：手机端回到 `/pages/mobile/login/index`，平板端回到 `/pages/tablet/login/index`。
- Mobile / Tablet 运行时跨端互跳已移除，新增 `pages/launch/index` 作为一次性设备分流入口；进入手机端或平板端后仅在本端内部导航。
- 微信小程序构建通过 `MP-WEIXIN` 条件编译只注册 `pages/launch/index` 与 `pages/mobile/*`，不包含平板端页面；`launch` 在小程序下固定进入手机首页。
- 平板端与手机端页面设计风格已全面实现同步（极简禅意体系：禅白、象牙白底、细发丝边框与 999rpx 胶囊组件）。
- 平板端侧栏首次页面切换的胶囊闪动已修复：`TabletLayout` 侧栏指示器动画缩短至 120ms，确保在 160ms 路由重载前至少预留 2 帧落位余量；新页面首帧导航索引改为优先读取当前路由，只有 store 路径与当前路由一致时才复用 store，并由 `scripts/check-tablet-sidebar-transition.mjs` 回归检查该时序与初始化规则。
- **平板端全景多栏架构重构完成**：摒弃手机端竖向单栏思维，升级为大屏多栏横向交互体系：
  - **首页 `dashboard`**：重构为左栏 62%（问候语、快建日程悬浮弹窗、周视图与前 4 项重点待办）+ 右栏 38%（全宽单列堆叠：顶部Hero卡收缩包裹文字，下方趋势、分布与热力图三卡等分剩余空间各约1/3高度）的非滑动全景控制台；左侧“添加日程”已升级为与手机端完全一致的顶层悬浮弹层（含遮罩层、学科竖排下拉菜单、0-2小时连滑分段时段拖动条），点击再不挤压下方布局；强调色全量升级为鼠尾草绿，放大了所有图表尺寸与字号；热力图精简为近16周/112天并采用 repeat(16, 1fr) x repeat(7, 1fr) 100% 均分布局、常驻提示栏消除初次加载跳动与死循环渲染异常，同时拉大间距 gap 至 10rpx 并加粗边框边界，大面积饱满铺满空间。
  - **学科工作区 `workspace`**：顶栏精缩为「文件、知识、总结、复习」四大支柱；采用极简禅意圆角浮动卡片双栏架构（左侧统一导航与列表卡片 + 右侧主工作区卡片，已调大左侧分栏抽屉宽度并升级为 `380rpx`~`45vw` 弹性响应式架构，精简文字描述标签并应用单行溢出保护防止折行）；彻底修复并优化侧栏文件选择响应式布局及交互：针对 CSS Flexbox 默认 `min-width: auto` 导致的侧栏容器宽度被内部横向滚动条或长文本撑破问题，对 `.tier2-drawer`、`.drawer-content`、`.drawer-scroll`、`.file-item` 及 `.summary-file-selector` 增加了严格的 `width: 100%; min-width: 0; max-width: 100%; overflow: hidden; box-sizing: border-box` 约束，彻底解决“文件选择框没有在框内、穿入侧栏框中”的穿模溢出异常；文件列表操作项支持 Flex 换行与响应式间距，总结与大纲顶端新增横向联动药丸选择器；主工作区新增响应式大屏文件详情与可手写标注专区（Photo/PDF Handwriting Stage），根据用户反馈“文件展示主要内容为照片和PDF、按钮简约、主体为可手写页面”，废除了原有的冗余文本卡片，直接在视窗中央呈现高清照片与 PDF 预览阅读层，并在顶层集成无缝叠加的自研手写笔迹引擎与标注画布（`HandwritingEngine` + `<canvas>`），支持使用钢笔、荧光笔、橡皮与色彩/线宽控制条在照片和文档上方直接圈画批注与推演；头部操作按钮与工具条全面精简为极简无表情符号样式（Zen Minimalist Style）；AI 助手由静态右边栏彻底升级为右下角悬浮球点击触发、支持按住顶部自由拖拽、底部左右下角边缘圆角描边滑动缩放且无遮罩的全屏自由浮窗；浮窗内部无缝嵌入了独立 AI 页的核心交互与样式并优化了内容居中适配（三大模型选择下拉栏、Spark 欢迎光环、快捷提问胶囊、Markdown 富文本渲染、复制/提炼知识块及多模态附件胶囊输入栏）；支持新建学科笔记草稿；全量收拢复习页面闪卡与滑动掌握度手势。
  - **独立 AI 助手 `ai-search`**：根据用户需求“把手机端宽屏适配就好了”、“扩展到全屏，用响应式布局”及“左边新增侧栏历史记录，把新增对话按钮也放侧栏里面”，采用极简禅意圆角浮动双卡片架构（左侧 440rpx 宽历史会话记录卡片，顶部内置“+ 开启新对话”按键，支持会话列表切换与单条删除；右侧主对话卡片废弃 `max-width: 1500rpx` 定宽截断，全量采用 `width: 100%` 搭配 `clamp()` 与分段 `@media` 响应式查询实现真正的全屏扩展与边距自适应）；在全局导航组件 `TabletLayout` 中将左侧导航侧栏与底部 136rpx 独立悬浮 AI 按钮统一包裹入 `.left-nav-column` 垂直 Flex 容器中（`align-items: center`），彻底解决了原有 `position: fixed` 独立定位导致侧栏与 AI 按钮未竖直居中对齐的问题，确保两者在任何设备上中轴绝对重合。
