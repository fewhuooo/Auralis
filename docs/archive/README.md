## Agent 禁止事项

- 禁止把归档中的“已完成”当成当前已验收。
- 禁止依据归档路径创建或恢复 StudyCore 命名的目录、包、路由或配置。
- 禁止从归档复制接口、字段或环境变量而不核对当前代码。
- 禁止把归档任务重新加入现行计划，除非用户明确提出并完成当前代码核验。

## 历史保真

归档文件顶部的警告属于归档元数据。警告之后的原始正文保持历史原貌，不进行事实修正。
