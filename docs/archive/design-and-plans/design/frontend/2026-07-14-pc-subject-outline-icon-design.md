# PC 学科线条图标设计

更新时间：2026-07-14

文档状态：待实施设计

权威范围：PC 学科的新建与编辑图标选择、持久化值及展示规则。

## 目标

让新建学科使用简约线条图标，同时保持已有以 Emoji 保存的学科在所有既有页面中原样显示。

## 范围与非目标

- 范围：`SubjectCreateModal`、学科大厅、学科工作区与任务创建选择器中的学科图标。
- 不迁移、不批量改写本地数据库中已有的 Emoji 值。
- 不更改 API、Store 数据结构或其他页面中与学科无关的 Emoji。

## 图标值与渲染规则

- 新建学科默认保存 `book`；创建器提供一组语义化图标标识（例如 `book`、`cpu`、`calculator`、`palette`）。
- 新建或编辑时主动选中的图标保存为该语义标识。
- 已有 Emoji 值不是语义标识，仍按原字符显示；编辑后若未重新选择图标，保存时保留原值。
- 语义标识在可嵌入组件的位置渲染为 Element Plus 线条图标；未知语义标识回退至 `book`。
- 原生 `<select>` 不支持嵌入 SVG：语义标识学科只显示名称，已有 Emoji 学科继续在名称前显示其 Emoji。

## 组件与页面改动

1. `SubjectCreateModal` 将 Emoji 网格替换为可访问的线条图标网格；预览区以同一渲染规则显示当前选择。编辑旧 Emoji 学科时保留 Emoji 预览，直到用户重新选择。
2. `subjectIcon` 工具集中识别语义标识、解析对应的图标组件，并提供 Emoji 原样展示所需的判断/回退逻辑。
3. `SubjectHall`、`SubjectWorkspace` 的卡片、侧栏与欢迎区改用统一渲染；新学科不再把标识文本或 Emoji 输出到模板。
4. `Timeline` 的学科选择器保留原生控件：旧 Emoji 作为选项前缀，语义化新图标不显示替代字符。

## 兼容性与错误处理

- 空图标值按书本线条图标渲染，但不在读取时写回数据。
- 未知语义标识使用书本线条图标；非语义字符串视为已有显示值并原样输出。
- 不改变 `Subject.icon` 的字段类型、同步语义或 API 契约。

## 验收与验证

- 新建学科：创建器、预览、大厅和工作区均显示同一个线条图标。
- 已有 Emoji 学科：大厅、工作区、欢迎页和任务选择器继续显示原 Emoji。
- 编辑旧 Emoji 学科且未更换图标：保存后仍为原 Emoji；主动更换后保存新的语义标识并显示线条图标。
- 更新现有学科图标渲染检查脚本并运行；执行 PC 生产构建。
- 浏览器或 Tauri GUI 人工检查仍单列为未完成的视觉验收，不以构建代替。
