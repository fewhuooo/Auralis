# Auralis 用户手册

更新时间：2026-07-10

文档状态：现行草案

权威范围：面向最终用户的主要操作流程、平台差异和常见问题

事实来源：当前 PC 路由、Mobile/Tablet 页面与产品需求

## 使用前说明

Auralis 目前处于“已构建待验收”阶段。部分功能需要后端、本地基础设施或 AI 服务；Tauri、微信开发者工具、手机和平板真机尚需单独验收。本手册描述当前预期操作，不表示所有平台都已生产可用。

## 登录与账号

1. 打开当前端登录页。
2. 输入用户名和密码。
3. 登录成功后进入首页或仪表盘。
4. access token 过期时，客户端尝试使用 refresh token 刷新。
5. 刷新失败后返回当前端登录页。

注意：PC 当前代码中的页面登录守卫临时关闭。即使页面可打开，受保护的后端请求仍应要求有效 access token。

## 首页与仪表盘

### PC

- 查看今日时间线和待办。
- 创建、完成或拖拽任务。
- 进入学科大厅、资产、时间线或个人设置。

### Mobile

- 横向切换周日期。
- 查看重点任务、专注时长和任务统计。
- 使用快速日程弹层添加任务。

### Tablet

- 左侧查看问候、周视图和重点任务。
- 右侧查看趋势、分布和热力图。
- 使用左侧固定导航切换学科、工作区、专注、复习和 AI。

## 学科与工作区

1. 从学科大厅选择学科。
2. 进入工作区后选择文件、知识或任务上下文。
3. 阅读资料、查看关系、提炼知识或创建任务。
4. 观察保存和同步状态后再切换设备。

Tablet 工作区默认优先显示文件。有资料时可自动选择第一个文件；“总结”按钮会切换右侧总结栏。

## 文件与资产

1. 在资产或工作区选择上传。
2. 选择支持的文件并等待上传。
3. 上传后等待绑定和解析状态更新。
4. 处理完成后进入阅读、提炼或问答。

若上传失败：

- 检查后端与 MinIO 是否运行。
- 确认文件没有超过服务端限制。
- 不要反复绑定同一个失败 objectName；重新获取预签名 URL。

当前对象存在性、真实大小和 MIME 校验仍需后端加固，不应上传敏感或唯一副本。

## 知识块

- 手工创建或从 AI 摄入结果生成知识块。
- 设置学科、标题、摘要、来源和颜色。
- 在工作区查看关联关系。
- 删除后等待同步完成，再检查其他端是否消失。

如果已删除内容在另一端重新出现，应停止继续编辑并记录同步 cursor、设备和操作顺序。

## 任务、排期与专注

1. 新建任务并填写学科、名称、描述、预计时长和负荷。
2. 在首页或时间线设置排期。
3. 进入 Pomodoro/专注页面开始计时。
4. 完成或中断后确认任务状态和统计变化。

拖拽排期不可用时，使用任务表单设置时间。切换后台或锁屏后，应核对剩余时间是否正确。

## AI 功能

当前 AI 入口支持聊天、流式回答、资料摄入、任务抽取、手写转换和排期建议。

使用原则：

- 提问前确认当前学科和来源文件。
- AI 输出可能不准确，形成知识或任务前应人工确认。
- 流式回答中断时可重试，不要把半段输出当作完整结果。
- 不在客户端输入或覆盖服务端 API key。
- 外部 AI 服务不可用时，保留原始资料和本地输入。

## 复习与统计

- 在 Review 查看待复习项目并提交结果。
- 在 Stats 查看学习时长、任务和趋势。
- 图表为空时先确认是否有本地记录、是否已登录和是否完成同步。
- 当前页面可能混合本地与服务端数据；以页面明确标识为准。

## 手写与批注

- Mobile 提供轻量手写入口。
- Tablet 支持文件批注、学科手写文档和随手记相关代码。
- Tablet 手写入口默认可被 `VITE_TABLET_HANDWRITING_NOTES_ENABLED` 关闭。

重新启用前必须在真实触控设备检查笔迹保存、文件切换恢复、平移缩放、橡皮、撤销、清屏和长时间书写。

## 设置与个人资料

- 修改主题、字体或交互偏好。
- 查看个人资料和账号入口。
- 主题切换后检查文字、图表和卡片对比度。
- 退出登录前确认本地待同步操作已处理。

## 常见问题

### 页面能打开但接口返回 401

PC 守卫当前可能没有阻止进入页面。重新登录并检查后端是否运行；不要把页面可见当作已登录。

### 文件一直处理中

检查 Server、MinIO、AI/解析服务和 WebSocket；查看资产状态接口和后端日志。

### AI 没有回答

检查 AI key、模型配置、网络和服务端日志。生产 profile 当前仍有配置键不一致风险。

### 另一台设备没有更新

确认两个设备使用同一账号，检查 push/pull、cursor、WebSocket 和 token；离线操作恢复后可能需要重新拉取。

### Tablet 看不到手写入口

入口可能被 feature flag 主动关闭。这是当前发布策略，不要依据历史文档恢复入口。

## 反馈信息

报告问题时请提供：平台、页面、操作步骤、期望、实际结果、时间、错误提示、网络状态，以及是否涉及登录、上传、AI 或同步。禁止提交真实密码、token 或 API key。
