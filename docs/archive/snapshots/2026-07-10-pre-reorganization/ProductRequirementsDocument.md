# Auralis 产品需求文档 v3

更新时间：2026-07-02

## 产品定位

Auralis（Auralis）是一个由云端大模型辅助的跨平台学习生产力系统。系统以“知识块”和“任务块”为核心，把碎片知识捕获、文档学习、手写整理、复习规划和任务排期串联成闭环。

## 目标用户

- 需要管理课程资料、笔记、复习计划和任务安排的学生。
- 需要在 PC、手机、平板之间流转学习资料的用户。
- 希望通过 AI 将 PDF、PPT、手写笔记和碎片想法整理成结构化知识的人。

## 核心场景

- 手机端：快速查看今日安排、捕获碎片想法、进行轻量学习。
- 平板端：阅读资料、手写笔记、复习卡片、专注计时。
- PC 端：学科空间管理、资产编排、知识图谱、任务排期。
- 后端：统一鉴权、同步、AI 编排、文档解析、对象存储和向量检索。

## 当前重构说明

前端页面目前仍在重构中。需求验收时需要区分：

- 页面代码存在：只代表已构建或正在重构。
- 构建通过：只代表语法和打包链路可用。
- 已验收：必须经过真实流程、接口联调、异常状态和权限边界检查。

当前 PC 端重点重构方向是学科大厅、学科工作区、资产编排和 Timeline；Mobile / Tablet 重点重构方向是平板 dashboard、subject-hall、workspace、handwriting、pomodoro、review、profile 等新页面。

## 功能模块

### 账号与权限

- 用户注册、登录、刷新 token。
- access token 用于受保护接口。
- refresh token 仅用于刷新接口。
- 用户数据必须按 `userId` 隔离。

验收标准：

- 新注册用户密码以 BCrypt 存储。
- 普通接口拒绝 refresh token。
- 用户不能访问其他用户的资产、知识块和任务。

### 知识块

- 支持创建、查看、更新、删除知识块。
- 支持按学科、来源、标签组织。
- 支持通过 AI 文档解析生成知识块。
- 支持本地优先写入后通过同步机制上行。

验收标准：

- 列表查询只返回当前用户数据。
- 删除语义需和同步机制保持一致。
- AI 生成知识块需要可追踪来源。

### 任务块

- 支持任务创建、排期、状态切换。
- 支持脑力负荷、预计时长、学科归属。
- 支持从知识块或 AI 提取结果转化为任务。

验收标准：

- 任务数据按用户隔离。
- 排期状态在本地和云端同步一致。
- 直接 CRUD 和同步路径的删除语义一致。

### 学科空间

- 支持按学科组织资料、知识块和任务。
- 支持 NotebookLM 风格的材料集合与学习工作区。
- 支持后续扩展知识图谱和 RAG 检索范围。

验收标准：

- 学科空间能关联资料、知识块和任务。
- PC 和移动端展示口径一致。
- 前端重构完成后，PC `/subjects`、`/subject/:id` 与平板 subject-hall / workspace 的入口和业务概念一致。

### 资产上传与解析

- 后端生成 MinIO 预签名上传地址。
- 前端直传对象存储。
- 后端绑定资产元数据并投递解析任务。
- Redis Stream 消费解析任务，生成知识块和向量数据。

验收标准：

- 资产绑定必须校验当前用户目录归属。
- 后续需补充 MinIO 对象存在性、大小和 content-type 校验。
- 解析状态能被前端查询或通过 WebSocket 感知。

### AI 能力

- AI 问答。
- 文档摄入和知识提取。
- 任务提取。
- 手写内容转 Markdown / LaTeX。
- 排期建议。

验收标准：

- 前端不暴露 AI API Key。
- 后端统一调用模型供应商。
- RAG、引用、上下文质量需单独验收。

## 非功能要求

- 安全：密码哈希、用户隔离、CORS 白名单、Token 类型校验。
- 可用性：基础构建链路稳定，后端可启动，前端可构建。
- 可维护性：接口、数据库、部署和运维文档保持同步。
- 可扩展性：AI Provider、向量库、对象存储应可通过配置替换。

## 当前范围

当前版本重点是整理现有功能、明确状态、补齐文档体系和关键验收缺口。完整 E2EE、生产级 RAG 评测、企业多租户权限和完整 CI/CD 不属于当前已验收范围。

## 当前验收缺口

- PC 登录守卫临时关闭，不能作为正式权限验收通过。
- Mobile / Tablet 页面处于重构期，平板统计页入口需要确认。
- 后端缺少真实测试源码，`mvn test` 通过不能代表业务验收完成。
- MinIO 对象存在性、大小、content-type 校验仍需补齐。
- WebSocket 握手鉴权、心跳续期、token 过期断连需要专项验收。
