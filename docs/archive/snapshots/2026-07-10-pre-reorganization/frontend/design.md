# 前端页面设计总览

更新时间：2026-07-10

本文档统一总结 Auralis PC、Mobile、Tablet 三类前端页面的功能设计、视觉风格、布局架构、交互细节、数据依赖和验收口径。页面状态以当前代码和 `docs/FrontendPC.md`、`docs/FrontendMobileTablet.md` 为基线；本文不描述后端接口细节，接口契约以 `docs/APIManifest.md` 为准。

## 1.5 统一视觉设计体系（Zen Minimalist）

三端共享极简禅意视觉体系，以下设计令牌和视觉规范在 PC、Mobile、Tablet 中保持一致：

### 1.5.1 色彩令牌

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| 禅白 (Zen Ivory) | `#F9F9F7` | 主背景色（浅色模式） |
| 石墨黑 (Zen Graphite) | `#1C1C1A` | 主文字色 |
| 鼠尾草绿 (Sage Green) | `#7D9372` | **品牌强调色**，按钮、开关激活态、进度条、图标高亮、图表主色 |
| 鼠尾草浅 (Sage Light) | `#A3B19B` | 辅助强调色、文字装饰色 |
| 发丝边框 (Hairline) | `#E6E6E4` | 统一分隔线、卡片边框，替代所有重投影 |
| 石色 (Stone) | `#A8A8A5` | 次要文字、占位符、禁用态 |

### 1.5.2 视觉风格规范

- **消除重投影与科技蓝**：全面废弃深色阴影和科技蓝色调，只保留极轻投影（`box-shadow: rgba(0,0,0,0.02~0.06)`）。
- **全圆角浮动卡片**：页面内各面板采用 `border-radius: 16px`（`--radius-lg`）+ `1.5px solid var(--border-default)` 发丝边框，形成浮动卡片视觉。
- **毛玻璃 (Glassmorphism)**：侧边栏、搜索框、弹窗等关键容器使用 `backdrop-filter: blur(20px)` + 半透明背景。
- **鼠尾草绿全量渗透**：首页强调色、设置开关、图标、进度条、图表柱、头像背景等全部统一至 `#7D9372`，不使用科技蓝或紫色。
- **渐变掌握度进度条**：学科卡片使用全圆角 + 鼠尾草绿渐变填充的掌握度进度条。
- **发丝边框统一**：所有卡片、面板、弹窗边框统一使用 `#E6E6E4` 或 `var(--border-default)` 发丝线，消除粗重 border。

### 1.5.3 排版与字体

- **主字体**：`DM Sans`、`Inter`、系统字体栈。
- **等宽字体**：`Fira Code`。
- **标题**：`font-weight: 700~800`，`letter-spacing: -0.2~-0.3px`。
- **正文**：`font-size: 12~14px`，`line-height: 1.5~1.7`。

### 1.5.4 动效与过渡

- **快速过渡**：`0.15s cubic-bezier(0.4, 0, 0.2, 1)` 用于 hover、focus。
- **正常过渡**：`0.25s cubic-bezier(0.4, 0, 0.2, 1)` 用于面板切换、颜色变化。
- **顺滑过渡**：`0.4s cubic-bezier(0.16, 1, 0.3, 1)` 用于多栏折叠联动、侧栏展开收起。
- **页面切换**：`opacity + translateY` 淡入淡出，`0.2s ease`。

### 1.5.5 深色模式

- PC 端支持 `html.dark` 类切换，背景色切换为暖炭色系（`#1f1e1c` / `#292825` / `#33312e`），文字切换为浅色燕麦色系。
- Mobile / Tablet 暂以浅色模式为主。

## 3. PC 页面功能设计

PC 端已于 2026-07-09 完成极简禅意（Zen Minimalist）体系视觉风格升级，全量迁移设计令牌为禅白 (`#F9F9F7`) 与鼠尾草绿 (`#7D9372`)，消除重投影与科技蓝，统一发丝边框 (`#E6E6E4`)。以下各页面设计说明包含布局架构、视觉风格和交互细节。

### 3.0 PC 全局导航架构

#### AppSidebar（左侧毛玻璃导航栏）

- 宽度固定 `68px`（`--sidebar-width`），全高 `100vh`。
- 毛玻璃背景：`backdrop-filter: blur(20px)` + 半透明白色（`rgba(255, 255, 255, 0.75)`）。
- 右侧发丝分隔线 `1px solid var(--glass-border)`。
- 顶部品牌区：28×28 SVG 品牌图标 + 鼠尾草绿到禅白渐变填充。
- 导航项：44×44px 正方形按钮，`border-radius: 10px`；hover 时显示鼠尾草绿半透明背景 `rgba(163, 177, 155, 0.15)`；active 时左侧 3px 高 20px 鼠尾草绿竖条指示器 + 浅色背景。
- 分隔线下方动态展示学科列表（40×40 学科图标 + 主题色背景），点击进入 `/subject/:id`。
- hover 时在侧边栏右侧弹出**毛玻璃浮动 Tooltip**（导航项）或**毛玻璃浮动学科卡片**（学科项，显示名称、描述、知识块数/材料数）。
- 底部同步状态指示灯：8×8 绿色脉冲圆点（就绪 `#22c55e`）/ 橙色（同步中 `#f59e0b`）。

#### AppHeader（顶部导航栏）

- 高度 `64px`（`--header-height`），背景色 `var(--color-bg-secondary)`，底部发丝线。
- 三段式布局：左侧页面标题（`font-weight: 600`）| 中部全局搜索入口（毛玻璃搜索框，`max-width: 460px`，hover 时鼠尾草绿边框发光 + `Ctrl+K` 快捷键提示）| 右侧工具区（深色模式切换、番茄钟占位、通知占位、用户头像）。
- 用户头像：32×32px 鼠尾草绿背景 + 白色首字母，右下角 10×10 绿色在线状态点。

#### SearchPalette（全局搜索面板）

- `Ctrl+K` 唤醒的全局命令面板，覆盖式毛玻璃弹窗。
- 支持知识块搜索、学科搜索、页面快速跳转。

### 3.2 Dashboard

| 项 | 设计说明 |
| --- | --- |
| 页面目标 | 作为 PC 首页，汇总近期学习状态、知识块、任务排期和学科入口。 |

| 中栏设计 | 为最纯粹和高阅读效率的**知识流列表（Knowledge Stream）**：顶部仅保留简约的“知识流”主标题，不放置顶端数据看板或热力图卡片；拉开卡片内间距（`18px 22px`），正文行高宽松舒适；卡片元数据中的学科微标签全量对齐至**浅鼠尾草绿背景+深色文字** (`rgba(163,177,155,0.22)` + `#2D3E25`)。 |
| 右栏设计 | 顶部 70% 紧凑时间轴（含大写字距标题与日/周视图选择，并将全栏唯一的圆形鼠尾草绿 `+` 新建任务按钮整合收拢至此处右上角，剔除待办清单头部多余的加号，做到极简精干）；下部 30% 待办清单（复选框 + 任务名 + 拖拽手柄），且每个待办事项（`.todo-item`）全面升级为**独立圆润的现代胶囊形态** (`border-radius: 9999px` + 微边框与微阴影，悬浮时轻盈浮动）；**时间轴对齐与当前时间条优化**：1. **单格对齐**：时间单格基准行高与 `HOUR_HEIGHT` 严格统一为 `52px`，消除行高与任务块高度换算累积误差；重置插槽上下内边距与基线偏移，让时间数字（如 `10:00`）与任务卡片顶部完全水平对应；多小时跨格任务精准联动 `filteredTimeSlots` 判断并隐藏被覆盖插槽，确保整条时间链条无任何位置偏差；2. **当前时间指示条 (`.current-indicator`)**：固定显示于当前小时与下一小时的正中间 (`top: 50%; transform: translateY(-50%)`)，无须随着分钟级流逝进行细碎换算，呈现出沉稳清晰、一眼可知当前所处的小时区段分割效果。 |
| 弹窗风格 | 1. **知识块详情弹窗** (`width: 640px`)，遵循**浅鼠尾草绿全局色彩规范 + 严格左对齐容器分层架构**：背景使用极浅鼠尾草绿 `#F2F5F3`（暗色下 `#181D18`），大圆角 `20px` 与轻盈悬浮阴影；头部信息区（微标签 Badge、中灰色辅助来源、主标题）在同一绝对垂直参考线上严格左对齐；核心内容放置于独立的纯白色 `#FFFFFF` 嵌套卡片；去除多余的内联代码或词汇强调背景框，强调词汇 (`Self-Attention` 等) 直接采用洁净粗体渲染；底部配置偏深鼠尾草绿 `#849C8A` 实心“确定”按钮。 <br/>2. **新建学习任务弹窗 (`.task-create-modal`)** (`width: 520px`)：**全面借鉴移动端的新建任务栏卡片化与高交互设计**，摒弃了传统 PC 枯燥的下拉选择框 `<select>`：① **任务名称**：采用带有平滑焦点高亮与鼠尾草绿光晕的现代输入框；② **所属学科**：采用**可视化胶囊网格选择 (`.subject-capsule-grid`)**，每一个学科以独立的圆润胶囊形态呈现（带学科图标与主题配色），点击后即时呈现专属色彩高亮；③ **专注时长**：结合了**预设选项胶囊 (`30分/60分/90分/120分/180分`) 与横向无级滑动条 (`range slider`)**，既有移动端的直观触摸滑感，又保留了 PC 一键点击粒度的高效；④ **脑力负荷**：采用**三列横向选择卡片 (`.load-card-grid`)** 分别对应「🌱 轻度专注 (1.0 🧠)」、「🌿 中度专注 (2.0 🧠)」与「🔥 深度沉浸 (3.0 🧠)」，选中的卡片会随鼠尾草绿主题微浮高亮；底部“添加到待办”按钮使用 `border-radius: 9999px` 实心鼠尾草绿胶囊样式。 |

## 6. 跨页面流程

### 6.1 登录与会话

1. 用户从 Login 登录或注册。
2. `useAuthStore` 保存 access token、refresh token 和用户信息。
3. PC、Mobile、Tablet 页面读取登录态后加载业务数据。
4. 退出登录时清理 token、本地用户状态，并回到登录页。

验收口径：刷新、冷启动、退出后再进入页面时，登录态表现一致。

### 6.2 学科到工作区

1. 用户在 Dashboard 或 SubjectHall 选择学科。
2. PC 跳转 `/subject/:id`，Tablet 跳转 `pages/tablet/workspace/index?id=<subjectId>`。
3. 工作区加载当前学科、资料文件、知识块和 AI 上下文。
4. 用户在工作区创建知识块或管理资料。

验收口径：跨端学科 ID、学科名称、知识块和资料数量一致。

### 6.3 资产导入到知识块

1. 用户在 PC Asset 或 Mobile asset 选择文件、拖拽文件或拍照。
2. 前端展示上传或解析进度。
3. 解析完成后生成资料记录和知识块。
4. 知识块进入 Asset、Timeline、Dashboard、Workspace 和 Review 的数据来源。

验收口径：导入完成后所有相关页面可刷新到新增知识块，失败时有明确反馈。

### 6.4 任务排期与专注

1. 用户在 Timeline、Dashboard 或 Tablet dashboard 创建任务。
2. 任务进入待办或时间槽。
3. 用户通过拖拽、完成、延后或专注计时更新任务状态。
4. 统计页和个人页展示累计专注和任务完成情况。

验收口径：任务状态在 PC、Mobile、Tablet 视图一致，完成和延后不会生成重复任务。

### 6.5 复习闭环

1. 知识块根据复习时间或掌握度进入 Review。
2. 用户完成复习并反馈掌握情况。
3. 前端更新知识块复习状态或创建后续复习任务。
4. Timeline、Stats 和 Dashboard 体现复习结果。

验收口径：复习后不应继续出现在当日待复习列表，下一次复习时间可追踪。

### 6.6 同步闭环

1. 前端通过 Store 和本地数据库记录知识块、任务、资料等变化。
2. `useSyncStore` 调用 Sync API 推送和拉取 mutation。
3. WebSocket 接收同步事件或文档解析事件。
4. 页面按事件刷新局部数据。

验收口径：离线变更、重新登录、冷启动和多端切换后数据不丢失、不串用户。

## 7. 页面通用设计约束

### 7.1 功能与数据约束

- 页面必须覆盖 loading、empty、error、unauthorized 或未登录状态。
- 页面新增接口调用前必须核对 `docs/APIManifest.md` 和后端 Controller。
- 涉及用户数据的页面必须通过 `userId` 或登录态隔离数据。
- Store 字段变化后必须同步更新对应页面说明和验收口径。

### 7.2 平台交互约束

- PC 端优先保证键盘、鼠标、拖拽和宽屏信息密度。
- Mobile 端优先保证单手操作、键盘遮挡处理和弱网反馈。
- Tablet 端优先保证横屏触控、多面板布局和导航可达性。

### 7.3 视觉风格约束（Zen Minimalist）

- 三端**品牌强调色统一为 `#7D9372`**（鼠尾草绿），不使用科技蓝、紫色或其他品牌色替代。
- 所有 toggle 开关激活态、主要按钮、进度条填充、图表柱状/线条主色必须使用 `#7D9372`。
- 所有卡片/面板边框使用 `var(--border-default)` 发丝线（`#E6E6E4`），不使用粗重 border 或深色阴影。
- 所有面板/卡片使用全圆角 `border-radius: var(--radius-lg)` 即 16px 以上。
- 弹窗/模态框使用半透明毛玻璃背景 + `backdrop-filter: blur` + 发丝边框 + 极轻投影。
- 页面背景统一使用 `var(--color-zen-ivory)` 即 `#F9F9F7`（浅色模式）。
- **不使用硬编码的半透明白色值**（如 `rgba(255,255,255,0.04)`）作为输入框背景，统一使用 `var(--color-bg-tertiary)` 等设计令牌。
- PC 端面板折叠/展开动画优先使用纯 CSS `width`/`opacity` 过渡，避免 `v-if`/`v-show` 导致的 DOM 销毁重建卡顿。
- PC 端深色模式下所有语义色变量必须通过 `html.dark` CSS 覆盖自动切换，不在组件内硬编码深色值。

## 8. 页面级验收清单

| 类别 | 检查项 |
| --- | --- |
| 路由与导航 | 所有正式页面可从导航或明确入口到达；未注册页面不应出现在正式导航中。 |
| 数据加载 | 首次进入、刷新、切换学科、退出再进入均能加载正确数据。 |
| 空状态 | 无学科、无资料、无知识块、无任务、无复习内容时有明确引导。 |
| 错误状态 | 登录失败、接口失败、上传失败、AI 失败、同步失败时有可理解提示。 |
| 数据一致性 | Dashboard、Timeline、Review、Stats、Profile 对同一任务和知识块的统计口径一致。 |
| 跨端一致性 | PC、Mobile、Tablet 对学科、知识块、任务、同步状态的基础含义一致。 |
| 权限隔离 | 未登录不可访问需要登录的数据；退出后本地状态和 token 清理正确。 |
| 平台适配 | Mobile 需验收 H5、小程序/App 目标平台；Tablet 需验收横屏和触控尺寸。 |
| 视觉一致性 | 品牌强调色统一 `#7D9372`；图表/开关/进度条/按钮不含科技蓝或紫色；卡片边框统一发丝线；弹窗统一毛玻璃风格。 |
| 深色模式 | PC 端 `html.dark` 切换后所有页面背景、文字、边框、阴影正确响应变量覆盖。 |
| 动画流畅 | PC 端面板折叠/展开、页面切换、拖拽排期等动画无明显卡顿或闪烁。 |
