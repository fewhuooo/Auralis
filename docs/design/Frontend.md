# Auralis 前端设计体系

更新时间：2026-08-22

文档状态：现行设计

权威范围：PC、Mobile、Tablet 的视觉令牌、页面结构、交互规则、跨页流程和体验验收条件

事实来源：当前路由与页面结构、现有样式实现与 2026-08-12 前端代码

## 设计目标

三端共享“极简禅意（Zen Minimalist）”语言，同时根据设备职责采用不同信息密度：

| 端 | 主要场景 | 设计重点 |
| --- | --- | --- |
| PC | 桌面学习工作台、学科与资产编排、时间线 | 高信息密度、多栏、鼠标键盘、文件预览、拖拽 |
| Mobile | 快速捕获、专注、复习、随身 AI、统计 | 单手操作、短路径、底部导航、弱网反馈 |
| Tablet | 横屏学习、文件阅读、工作区、手写与伴读 | 左侧导航、多栏全景、触控、手写、面板联动 |

设计文档定义目标行为，不负责维护构建或验收状态；状态见 [当前状态](../current/Status.md)。

## 统一视觉令牌

### 色彩

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| Zen Ivory | `#F9F9F7` | 浅色主背景 |
| Zen Graphite | `#1C1C1A` | 主文字 |
| Sage Green | `#7D9372` | 品牌强调、小标签、输入框激活态、小操作项 |
| Sage Light | `#A3B19B` | 辅助强调、AI 悬浮入口、装饰 |
| Primary Gradient | `linear-gradient(135deg, #A3B19B 0%, #7D9372 100%)` | 全局主要大面积操作入口（如新建按钮、表单提交等），提供统一的立体悬浮感 |
| Hairline | `#E6E6E4` | 卡片边框和分隔线 |
| Stone | `#A8A8A5` | 次要文字、占位和禁用态 |
| Error | 暖红低饱和色 | 错误、危险操作，不替代文字说明 |

禁止重新引入高饱和科技蓝作为主色。强调色应服务层级和状态，而不是装饰性铺满。
> **注意**：原用于主按钮的深色纯绿（如 `#849C8A` 或纯色 `#7D9372` 背景）现已废弃。所有页面的主要大面积操作入口（Primary Action）必须统一使用 `Primary Gradient` 线性渐变绿，以保持极简禅意的一致视觉语言。

### 表面与圆角

- 页面背景使用禅白或暖灰白，不使用纯白大面积强对比。
- 主卡片采用 `16px` 左右圆角、发丝边框和极轻阴影。
- 胶囊按钮和筛选器可使用全圆角，但长正文容器不得滥用胶囊形态。
- 侧栏、搜索、弹层可使用 `backdrop-filter: blur(20px)`，必须提供不支持毛玻璃时的实色后备。
- 阴影透明度控制在 `0.02–0.06`，禁止厚重悬浮阴影。

### 排版

- PC 普通 UI 文本统一使用 `var(--font-family-base)`（DM Sans 优先，系统无衬线回退），页面组件不得再声明独立的 Inter、Outfit、Plus Jakarta Sans 等字体。
- 代码、知识图谱节点等确需等宽的内容统一使用 `var(--font-family-mono)`（Fira Code 优先，系统等宽字体回退）。
- PC 根字号固定为 `16px`；语义字号使用 `caption`（12px）、`body-sm`（13px）、`label`（14px）、`body`（16px）、`body-lg`（18px）、`title-sm`（20px）、`title`（24px）和 `title-lg`（30px），番茄钟等大数字使用 `display-sm`（48px）或 `display`（72px）。
- 标题字重 `700–800`，字距轻微收紧。
- 正文行高 `1.5–1.7`；手机正文不得因追求精致而低于可读尺寸。
- 次要信息只能降低对比，不能依靠过小字号隐藏。

### 动效

| 场景 | 时长 | 曲线 |
| --- | --- | --- |
| hover / focus | `150ms` | `cubic-bezier(0.4, 0, 0.2, 1)` |
| 颜色和普通面板切换 | `250ms` | `cubic-bezier(0.4, 0, 0.2, 1)` |
| 多栏展开、折叠和联动 | `400ms` | `cubic-bezier(0.16, 1, 0.3, 1)` |
| 页面进入 | `200ms` | `ease` + opacity/translateY |

- 动效必须表达状态变化，禁止为装饰阻塞首次操作。
- 路由切换与导航指示器时序必须避免“先回旧位置再跳新位置”。
- 尊重系统减少动态效果设置。

### 深色模式

- PC 以 `html.dark` 为入口，背景使用暖炭色 `#1F1E1C`、`#292825`、`#33312E`，文字使用浅燕麦色。
- Mobile / Tablet 当前以浅色为主；在完整定义令牌、图表、图片和手写画布之前，不宣称深色模式支持。

## 通用交互状态

每个数据页面必须设计：

- 首次加载骨架或进度，不出现无解释空白。
- 空状态说明“为什么为空”和下一步操作。
- 请求失败展示用户可理解的原因、重试和安全退路。
- 保存中、已保存、同步中、离线、冲突和失败状态可区分。
- 删除等危险操作明确影响和可恢复性。
- AI 长任务展示输入上下文、处理状态、失败和重新执行入口。

## 导航与跨端原则

- 同一端内部导航稳定，禁止因窗口尺寸变化在 Mobile 与 Tablet 路由间自动反复跳转。
- `pages/launch/index` 只负责首次设备分流；进入某一端后保持该端导航体系。
- 微信小程序固定进入手机体验，不注册 Tablet 页面。
- 登录失效回到当前端登录页：手机 `/pages/mobile/login/index`，平板 `/pages/tablet/login/index`。
- 当前 PC 守卫虽然临时关闭，设计上仍要求受保护路由在未登录时返回 `/login`。

| Dashboard | `/` | 今日概览、时间轴、待办和快速创建 |
| SubjectHall | `/subjects` | 学科浏览、搜索、创建和管理 |
| SubjectWorkspace | `/subject/:id` | 文件、知识、任务、关系和 AI 上下文工作区 |
| Asset | `/asset` | 上传、处理状态、资料编排 |

| Profile | `/profile` | 账号、偏好与主题设置 |

### PC 全局框架

- 左侧毛玻璃主导航保持窄栏，当前选中项必须同时用位置、形状或文本表达，不能只靠颜色。
- 全局搜索可使用 `Ctrl+K`，必须提供可点击入口与键盘焦点管理。
- 主内容采用响应式卡片网格；低宽度下优先保证主任务，不强行保留所有并列栏。
- Tooltip、菜单和弹窗必须脱离可能裁切的 transform/overflow 容器。

### Dashboard

- 左侧或主区聚焦今日时间线；任务块与时间格共享同一高度基准；时间栏顶栏的日视图与周视图切换采用全圆角胶囊风格（border-radius: 9999px）的并排切换按钮。
- 时间轴数据窗口固定为当前/所选日期所在的完整自然周（周日至周六）；首页和独立时间轴使用同一窗口，避免 `dayCode` 在跨周场景映射到下一周。首页日期格在日数字上方显示 `Sun` 至 `Sat` 英文星期缩写，7 个日期均匀分布，未选中态无边框，选中态使用固定约 `36px × 36px` 的圆形绿色背景；顶栏以“时间轴 · X月”提供月份坐标。已完成或已过去的任务只要保留 `scheduledAt` 仍显示，取消任务不显示。日视图以半小时槽位承接任务开始时间，任务块高度与半小时槽位及间距一致，已过去任务保留内容并以删除线标记。排期队列只接收有 `dueAt`、无 `scheduledAt` 且未完成的任务。
- 当前时间指示器清晰但不持续造成布局抖动。
- 待办使用独立圆润条目，复选、标题、拖拽手柄各有足够点击区域。
- 新建任务入口唯一且明确，禁止同一区域重复放置多个“+”。
- 首页统计或热力图是否显示由当前产品范围决定；移除的卡片不得因参考归档而恢复。

### SubjectHall

- 学科卡片展示名称、进度或掌握度和明确进入入口；注册后没有学科时展示真实空状态，不注入“未分类”占位卡片。
- 创建与编辑采用统一弹层，不让卡片网格在操作时重排。
- 编辑已有学科时保留服务端版本并提交 `baseVersion`，名称、描述和图标修改成功后关闭弹层并更新卡片状态。
- 学科卡片删除沿用统一确认和软删除反馈，历史遗留默认标记不改变删除能力。
- 搜索、空状态和大量学科时的滚动行为可预测。

### SubjectWorkspace

- 目标是“选择资料或知识 → 在主区阅读/编辑 → 在辅助栏查看关系、总结或任务”。
- 学科图标需在大厅、工作区、首页、时间线和全局功能侧栏保持一致；新建学科使用语义键对应的线条图标，已有 Emoji 原样显示，空值或未知语义键使用统一书本线条图标回退。创建时不提供主题色选择，新学科、工作区左下角及功能侧栏学科图标统一使用 Sage Green `#7D9372` 底色与白色图标。
- 多栏应允许聚焦主内容；辅助栏关闭后释放空间，而不是留下空白占位。
- 文件预览统一由 `FilePreview` 承载加载、失败、下载和不支持状态；当前 PC 先用自托管 File Viewer 覆盖 PDF、DOC/DOCX、PPT/PPTX、图片和文本，Excel/未知格式在上传前拦截。真实 DOC/DOCX 排版或资源兼容性不足时，替换组件内部 renderer 为服务端转 PDF，不改变学科工作区交互契约。
- 知识图谱是关系探索辅助，不能成为访问知识块的唯一方式。
- AI 提炼必须显示当前学科和来源文件上下文。
- 登记本地参考文件弹层必须明确显示选择文件、名称和归档学科三个前置条件；确认按钮在缺少任一条件或上传中禁用。上传中显示进行中状态，上传/登记失败以可理解通知反馈且保留弹层，允许用户修正后重试；成功后关闭弹层并刷新当前学科资料列表。浏览器直传使用服务端返回的可达预签名地址，不把容器内部 hostname 暴露给用户。

### Asset 与 Timeline

- Asset 明确区分待上传、上传中、处理中、完成和失败。
- 资产库的“全部任务”与学科任务目录展示当前用户的真实 Task Store 数据，不显示固定演示任务；任务按 `未分布`、`未完成`、`已完成` 并列分组，组内按截止时间排布。任务编辑使用 30 分钟步进的预计用时选择，不再显示认知负荷按钮，并通过显式保存写回任务详情。时间轴导入入口通过 `/asset?focus=unassigned-tasks` 聚焦未分布任务。
- Timeline 拖拽必须有落点反馈、冲突提示和键盘/表单替代操作；已排期任务拖到新槽位时必须以目标槽位写回 `scheduledAt`，不能沿用拖拽前的时间。
- 排期修改与任务状态修改不得产生互相覆盖的无提示保存；完成任务不自动清除排期，移出排期必须是显式操作。

### Pomodoro

- PC 专注页使用宽屏双栏结构：左侧为计时核心与环形进度，右侧为当前任务选择和今日数据。
- 开始、暂停、重置、专注完成和休息阶段必须有明确的文字或状态反馈；任务选择使用可读的胶囊式控件。
- 计时完成后更新任务 Store 的专注统计；浏览器/Tauri 的后台、刷新和长时间计时行为仍需人工验收。

### Profile

- 账号信息、外观和偏好分组，危险操作单独区域。
- 主题、字体等设置即时预览并可恢复默认。
- 账号区同时展示当前 user/device/session 状态；登录会话列表支持查看当前设备并撤销其它会话，加载失败必须有明确状态。
- 个人空间提供“退出登录”按钮；确认后清理当前本地会话并跳转登录页，服务端 logout 异常需要以通知反馈，不能阻断本地退出。

### Mobile 全局框架

- 使用底部悬浮胶囊导航和独立 AI 入口时，必须避开系统安全区与输入法。
- 主要操作位于拇指可达区域；返回、保存和危险操作位置稳定。
- 弹层优先使用底部 Sheet；键盘弹出时输入框与主操作保持可见。
- 离线时允许继续的功能必须给出本地保存和待同步提示。

### Home

- 周日期支持水平切换，当前日期、选中日期和有任务日期可区分。
- Home 只展示 Task Store 的真实排期；服务端或本地没有任务时保持空态，不注入设计演示日程或虚构学科。
- 专注时长和任务统计保持简洁，不挤占重点待办。
- 新建日程弹层包含学科、时间、时长和描述，滑杆必须有精确数值反馈。

### AI、Review、Pomodoro、Stats

- AI 会话显示用户输入、模型回复、生成中、取消、重试和来源上下文。
- Review 一次聚焦一个复习单元，结果反馈影响后续安排时必须可解释。
- Pomodoro 在后台、锁屏或页面切换后保持时间语义正确。
- Stats 对本地、服务端和模拟数据做清晰区分，图表颜色统一为 Sage。
- 2026-08-20 起，Mobile Stats 不再展示随机示例数据；服务端没有提供的学科分布保持空态。Review 只展示服务端 due 队列，提交不可变事件后才推进卡片，右滑不伪装撤销已提交事件。Pomodoro 任务选择器无待办时保持真实空态，完成专注写入按 user/device scope 隔离的 Store 计数。Mobile 手写识别链路未接通时只保留本地画布，不伪造 OCR 或知识块结果。
- 注册成功会直接建立会话并进入当前端首页；密码不足 12 字符在注册提交前提示。Settings 在服务端没有注册时间字段时不显示伪造加入天数。Asset 失败必须保持失败态，不允许以模拟进度或本地条目伪装上传成功。
- Tablet AI 新对话先创建 Conversation，历史会话来自 Conversation API，删除携带服务端版本；无历史时显示空态，不注入示例会话。图片快捷入口在上传链路未接通前明确提示，不伪造识别结果。

### TabletLayout

- 左侧导航与底部独立 AI 按钮共享垂直中轴。
- 导航指示器先落位再发生路由重载；当前实现的设计时序为 `120ms` 指示器与 `160ms` 路由切换。
- 模态内容通过独立插槽脱离 transform 堆叠上下文，避免 AI 浮窗溢出。
- 触控目标、滚动区和悬浮层不得依赖 hover 才能访问。

### Dashboard

- 左栏约 62%：问候、快速日程、周视图和重点任务。
- 右栏约 38%：Hero、趋势、分布、热力图垂直组织；当前 Hero 使用 `Primary Gradient`，热力图在 Tablet Dashboard 以 5 周正方形日历网格展示。
- 快速日程使用顶层遮罩弹层，不挤压主布局。
- 热力图使用固定占位和提示区，避免首屏尺寸变化导致跳动。
- Dashboard 图表只展示 Stats 服务返回的数据，不用随机值补齐空白日期；无学科时显示真实空态，不注入示例学科。
- Review 只从服务端 due 队列建立卡组，ReviewEvent 保存成功后才推进；右滑取消当前手势，不伪造对不可变事件的撤销。

### Workspace

- 默认进入文件面板；有资料时选择第一个文件作为阅读上下文。
- 所有主卡片头部采用统一高度基线，避免多栏底线错位。
- “总结”是主工具栏开关：打开时平滑折叠左栏并展示右侧总结栏；关闭时恢复。
- 禁止通过反复销毁 DOM 制造卡顿，面板切换优先使用稳定状态与 CSS 过渡。
- 文件区支持图片、PDF 和手写标注层；保存、切换文件和恢复批注必须有状态反馈。
- AI 浮窗继承当前文件和学科上下文，但不得遮挡关键工具。
- PC 学科工作区的文件项只负责选择；选择后中栏优先展示文件总结，不默认打开原文件。
- 学科大纲顶部只保留“AI 梳理”和圆形“+”；“+”进入左栏内联编排，章节可排序，小节只可在所属章节内排序。该编排当前是静态原型，刷新不保留。
- PC 右侧 AI 伴读复刻手机端的渐变四芒星、脉冲星环、用户名欢迎态、星形头像、石墨用户气泡、细边框助手气泡、三点输入中状态和纯文本胶囊输入；保留现有流式对话与材料上下文，不提供附件或麦克风入口；清空与发送使用带可读标签的图标按钮。学科工作区每次进入或切换学科均创建新的伴读会话，不恢复之前的聊天记录。

### AI Search

- 左侧为历史会话和新建对话，右侧为自适应全屏对话。
- 会话切换、删除和新建不丢失当前输入；删除需要明确确认。
- 对话区宽度使用响应式边距，不设置导致大屏中央截断的固定 max-width。

## 跨页面流程

### 学科到工作区

```text
学科大厅选择学科
→ 工作区加载学科上下文
→ 选择文件/知识/任务
→ 阅读、提炼、关联或排期
→ 保存本地并进入同步状态
```

### 资产到知识

```text
选择文件
→ 获取预签名 URL
→ 上传并绑定资产
→ 等待解析
→ 查看来源内容
→ AI 提炼
→ 用户确认后形成知识块或任务
```

### 任务到专注

```text
创建任务
→ 设置学科、时长和排期
→ 在时间线或首页选择
→ 开始专注
→ 完成/中断
→ 更新任务与统计
```

## 可访问性与输入

- 所有图标按钮提供可读标签。
- 键盘焦点顺序与视觉顺序一致，focus 状态不可移除。
- 颜色不是唯一状态信号；图表提供文字摘要或数据值。
- 拖拽、手势和 hover 操作提供点击、键盘或表单替代。
- 弹窗打开后焦点进入，关闭后返回触发元素。
- 手写和双指缩放只在支持设备上启用，并提供误触防护。

## 页面级验收清单

每个页面至少检查：

1. 路由入口与返回路径正确。
2. 未登录、token 过期和退出行为符合当前端。
3. loading、empty、error、offline、saving、synced 状态可识别。
4. 主要任务不需要依赖归档中的旧入口。
5. 小屏、常规宽度和目标大屏下无关键内容裁切。
6. 键盘、鼠标、触控和系统安全区符合目标平台。
7. 动效不造成首次点击闪回、白屏或布局跳动。
8. 数据来源、用户归属和同步状态清楚。
9. AI 输出、上传与解析失败可重试。
10. 构建通过与人工交互验收分别记录。
