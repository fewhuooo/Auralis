# Auralis 部署测试前门禁

更新时间：2026-11-15

文档状态：现行候选验收清单

权威范围：候选版本进入受控部署测试前的验收分类、证据与放行条件

事实来源：[当前状态](../current/Status.md)、[问题登记](../current/IssuesAndReview.md)、现行模块与契约

## 使用方式

R0–R6 与原任务 ID 保留，便于旧交接定位。下表是每个候选需要核对的门禁，不表示所有实现都未开始，也不继承早期勾选状态为当前通过。原始逐项勾选、命令和执行记录完整保存于[整理前快照](../archive/maintenance-2026-11-15/planning/PreDeploymentReadinessTasks.md)。

每个候选记录 commit、工作树差异、目标平台、环境、命令及退出码、人工证据、剩余风险和负责人。已有证据仅在源码/环境与验证范围仍适用时引用，不机械重跑已完成迁移，也不合并不同版本的定向结果为全量通过。P0 必须关闭；保留 P1 需明确接受记录及补偿措施；P2 可排入后续优化。

本文不授权部署、重启、删除数据或更改凭据。实际操作按[部署指南](../operations/Deployment.md)、[Runbook](../operations/Runbook.md)与仓库授权规则执行。

## 范围

候选端包括 PC Web/Tauri、Mobile H5、微信与 Tablet 主工作区，实际发布组合在 R0 确认。Tablet 手写云同步、其他小程序平台、旧 Server 数据自动迁移、跨实例事件 Broker、AI 自动执行领域写操作不因本清单纳入范围；改变产品范围需单独决策。

## 验证与证据入口

命令由 [PC](../modules/FrontendPC.md)、[Mobile / Tablet](../modules/FrontendMobileTablet.md)、[后端](../modules/Backend.md)、[基础设施](../modules/Infrastructure.md)和运维文档维护。当前 `postgres-it` profile 与 Mobile `test:tablet` 命令已存在；执行前仍须核对 Docker、TLS fixture、账号与目标平台前置条件。
