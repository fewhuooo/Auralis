# 文档与验收计划

更新时间：2026-07-02

## 目标

让文档变成开发过程的一部分，而不是事后补材料。本计划覆盖 `docs/`、`docs/plans/`、验收记录和交付口径。

## 当前事实

当前文档体系：

- `docs/README.md`
- `docs/plans/`
- `docs/archive/`
- `AGENTS.md`

当前风险：

- 代码仍在重构，文档需要随代码持续更新。
- 构建通过和人工验收容易混淆。
- 尚未建立正式人工验收记录模板。

## 人工验收记录建议格式

| 字段 | 说明 |
| --- | --- |
| 验收日期 | 使用绝对日期 |
| 验收人 | 人工确认者 |
| 模块 | PC / Mobile / Backend / Infra / AI |
| 场景 | 具体流程 |
| 结果 | 通过 / 未通过 / 阻塞 |
| 证据 | 命令输出、截图、日志、问题链接 |
| 后续动作 | 未通过或阻塞时必须填写 |

## 完成定义

- 每个领域计划都有任务编号和验收标准。
- 每次代码改动后，相关文档能被同步更新。
- 发布前能从文档看出当前风险、构建状态和验收状态。
