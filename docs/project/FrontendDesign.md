### 2026-11-15 登录与邮箱验证

登录页提供登录、注册和找回密码。验证码在当前表单输入，发送时禁用冲突操作，重置后回到登录并保留邮箱。PC 在验证码输入框右侧内嵌「发送验证码」文字操作，使用细分隔线区分输入和操作，发送和冷却期间显示对应状态。新密码的提示为「密码至少 8 位，且包含大写字母、小写字母和符号」，超出长度上限时提示缩短。PC 使用透明窗口拖动区，最小化、最大化或还原、关闭按钮在顶栏悬停或键盘聚焦时显示。

### 2026-11-13 首页搜索与任务反馈

- 退出或切换登录会话立即关闭全局搜索并清空结果。登录页不响应打开搜索的操作。
- 日程任务写入期间暂时禁用该任务的勾选操作。写入失败时提示原因，复选框按实际任务状态恢复。
- 首页快速创建提交后显示「保存中…」，期间禁用再次提交和关闭。保存失败时保留表单并显示错误，用户可原样重试；保存成功后关闭弹窗。

### 2026-11-12 大纲 Markdown 极简排版与视觉节奏体系

对学科工作区侧边抽屉的大纲卡片（`FileOutlineList.vue` 与 `SubjectOverviewSection.vue`）实施视觉规范升级，确立 Zen Minimalist 大纲层级：
- **H1（主题层）**：`13.5px / 700`，字色 `var(--text-primary)`，前置 5px 实体圆点，底嵌发丝边框，与卡片外框形成和谐呼应，去除传统浏览器标题默认超大字号与过重字重的突兀感；
- **H2（议题模块层）**：`12px / 650`，段前 `13px` 间距建立结构分段，左嵌 `3px × 11px` 的 Zen Sage 垂直药丸胶囊微晶指示条（`var(--color-primary-accent, #8B9A6E)`），明确知识模块边界；
- **H3（小节层）**：`11.5px / 600`，前置 4px 方形微晶标记；
- **列表与要点（UL / LI）**：段落间隙 `5px`，左侧预留 `14px` 缩进并搭配 `4.5px` 浅草绿柔和微圆点（`opacity: 0.65`），悬浮交互微弹放大；支持嵌套空心环列表与有序列表优雅 counter 编号；
- **暗色模式（Dark Mode）**：各字阶与边框严格绑定 `:root` 与 `html.dark` 设计语义 Token，代码块与引用块适配微光底色，实现全主题一致的沉浸呼吸感。

### 2026-11-12 Overview Markdown 展示与大纲编辑

大纲与总结分别作为 Markdown 展示，原大纲编排入口改为直接编辑 Markdown，保存不得清空为全空白。沿用现有总览入口、停止/重试和冲突操作。生成刷新期间保留上一份有效缓存；新的生成结果不覆盖未保存编辑。旧章/节内容不自动转换为 Markdown，不把旧格式不可用或仅有版本元数据的冲突响应渲染成空白成功结果。源码已接入；验证边界见当前状态。

文件重解析后，当前修订的大纲就绪时可编辑。若仍打开旧修订的未保存草稿，编辑器以只读方式保留文本供复制，点击「放弃草稿并切换版本」即可切换。文件和学科的大纲均可在保存等待期间继续输入，新输入留在编辑器中待下一次保存。

### 2026-11-11 开启新对话失败的恢复

学科工作区开启新对话失败时提示失败原因，保留用户输入，并恢复仍在当前账号和学科下的原会话操作。原任务正在执行时继续查询状态并允许停止；状态未知时继续显示显式恢复入口。成功创建后切换至新会话。

### 2026-11-11 桌面本地数据库启动状态

桌面端打开本地数据库时通过统一的 `StartupSplashScreen` 显示禅意极简启动过渡界面（提前应用持久化明暗主题与无边框窗口拖动区）；数据库初始化失败时保留「无法打开本地数据库」和「重试」按钮，点击后返回启动状态。数据库就绪且处于已登录会话时，同一过场顺畅衔接本地学习数据加载、工作区路由预加载与有界初始云同步预热，就绪后以纯 GPU 合成渐隐进入首页工作台。

### 2026-11-11 文件预览失败恢复

文件预览加载失败后，学科工作区与资料库均可在错误区域点击「重试」，重新加载当前文件；加载期间显示原有加载状态，避免重复请求。复用现有小号文字按钮，不改变正常阅读布局、配色或分页操作。恢复由用户主动触发，不自动重试；没有下载操作入口时不提示下载。

已有云端原件的资料若本机副本大小或哈希校验失败，预览会尝试从云端取回原件。本机副本保留，未完成上传的草稿仍显示本机读取错误。PDF 解码报错或阅读器 60 秒内未就绪时，错误区显示本地化提示和「重试」，点击后重新加载当前文件。

### 2026-11-11 搜索确认与复制反馈

- 更改搜索词后，等待当前检索完成再接受结果选择；回车不能确认旧结果，中文输入法选字的回车不导航。
- 知识详情复制在 Clipboard API 不可用时尝试浏览器降级复制，保留阅读焦点及选区；复制失败明确提示手动复制，不显示成功状态。沿用现有按钮、消息提示及样式。

### 2026-11-13 资料管理预览与星图范围

从学科分类打开文件后，资料树刷新沿用当前学科星图。从汇总分类打开时继续显示全局星图。当前文件同步删除后，资料阅览区和星图返回各自的空态。

### 2026-11-11 学科与资料编辑反馈

- 新建或编辑学科时，若本机另一门活动学科已使用同一名称（忽略首尾空白和大小写），提示更换名称并保留表单。编辑时可以保留原名并修改其他字段。
- 资料库知识块未保存的标题和正文在后台刷新期间保留。同步删除后退出详情；保存时若内容版本已经变化，保留草稿并提示重新打开条目，不把旧编辑静默覆盖到新版本。
- 学科工作区读取本地资料不等待 Chat 初始化；Chat 请求未返回期间可以浏览缓存文件，输入与引用保留，当前学科会话就绪后才允许发送。初始化失败可使用现有新会话操作恢复。沿用现有页面结构、控件与样式。

学科工作区的知识块详情随同步更新。编辑遇到新版可先查看最新内容，再保留已输入的字段继续编辑。已保存但未同步的修改在列表可见，冲突在同一详情中处理。手动录入和选区保存期间禁用再次提交，失败保留原输入。

### 2026-11-13 复习轮次内的失败恢复

提交、核对或完成学习失败时，在当前卡片旁显示原因。可按原样重试已经提交失败的操作，遇到复习进度冲突时重新确认。读取失败可重试读取。知识块版本已变化、当前轮次已无法继续时，返回规划后重新开始。恢复按钮沿用复习页现有样式，处理过程中显示进度提示。

### 2026-11-11 未核对复习的继续入口

复习初选后尚未完成确认或纠正的卡片，即使暂定日期已经在未来，也保留在计划复习入口可进入的队列中。结束本轮或重开后进入正文核对，沿用原选择；完成核对后才退出待核对列表。入口显示去重后的可继续数量及待核对提示，不改变现有布局、样式、自测和评分交互。

### 2026-11-11 资料导入与手动恢复

- 网络中断后保留暂停状态，网络恢复、同步刷新及重新启动均不主动重试；用户在处理中心点击继续后才恢复。本地草稿与已登记资料采用相同规则，已有解析产物继续复用；解析超时等非网络错误的既有重试策略保持。
- 处理中心在本机上传完成后继续展示服务端索引或失败状态；服务端 READY 才退出处理中列表，失败保留既有重试入口。
- 文件显示标题与原文件格式分离，用户可以使用不带扩展名的标题。预览和解析使用资产的原文件名；换选文件后默认名称跟随新文件，用户自定义标题保留。资料库外层拖入的文件直接预填登记弹窗。
- 原文件在本机等待上传完成时可预先登记为本机草稿。原件确认就绪后同步登记；临时上传失败按队列退避到期重试。手动同步显示尚未完成或失败的原文件上传。
- 资料库文件列表和选中项使用同一份状态。服务端 Source 确认就绪时显示「已就绪」。仅本机提交完成时显示「已提交，等待索引」，服务端索引或失败后显示对应状态。本机进度只对应当前资料版本。
- 文件选择器与拖放可以交替使用，最终提交最近一次选择；重新选择原生选择器此前选过的同一文件也必须更新，用户自定义标题保持。
- 沿用当前布局、样式和现有操作控件。

### 2026-11-11 PC Chat 断流状态反馈

断流后保持服务端实际运行状态并查询确认：执行中保留停止能力，UNKNOWN 提供显式恢复，终态更新消息并解除忙碌。超过有界查询次数时明确提示状态尚未确认，不把未确认执行显示为成功或自动重新提问。切换或重新加载会话后，旧请求及清理回调不改变当前会话展示。失败回复在终态历史刷新后仍保留原 run 的重试身份。

连接在首帧前结束时提示用户重试原请求。恢复会话期间保留输入及引用，完成历史更新后才开放新提问。

### 2026-10-31 Chat 渲染管线与轻量化渐进渲染优化

- **先思考完成再出现正文与分层流速控制**：在会话主界面建立“思考完成门禁”，当 AI 输出包含思考链或工具调用时，正文气泡与光标保持等待，直到思考链在胶囊内完整展开并平滑落定（状态转为“已深度思考”）后正文才挂载呈现；无思考输出时则即时响应。思考链统一采用柔和灰色字体（`var(--text-muted, #78716c)`），思考链顶栏胶囊仅展示思考状态（“深度思考中…” / “已深度思考 · X 字”），不保留工具调用提示，展开后的工具调用作为步骤卡片嵌入思考链内部流淌，不堆叠在思考内容最上方。思考链保持敏捷推流，正文流式采用放缓的阻尼步长（约 150ms 出一字），网络结算收尾时不发生文字快闪。
- **先外框后内部逐个渲染与极简化卡片设计**：组件挂载或生成时先稳定渲染最外层极简卡片框架（彻底去除点阵网格底纹与多余的 [R]/[S]/[V]/[D] 图标徽章，仅保留 Zen Sage 纤细边框与纯净底色）；移除预设冗余的“学习脉络”、“步骤拆解”等保底类型标题，若模型未下发 title 则完全不渲染多余标题栏，当下发真实 title 时直接清晰大方呈现；随后内部每一个组成结构（步骤条目、对比维度、脉络节点、图表数据）按 140ms 节奏逐个渐进展开，配合轻量 `node-mount` 弹性淡入动画。保持极简、克制且聚焦内容的原生卡片结构。
- **流式 Markdown 内存态补全与暂扣**：完善标签前缀与自定义容器暂扣缓冲，杜绝中间源码裸露；实现代码块、数学公式（`$$`、`\(`、`\[`）、粗体、行内代码与链接的流式语法镜像补全；强化末尾 Token 水墨渐显包裹。


### 2026-10-31 Timeline 连续拖动与后台结算

未完成网络同步的排期不阻挡后续本地拖动；每次拖动本地保存后即可继续，原有空槽顺延、主体后接和标题交换规则保持。后台回执不得使后续已保存的位置跳回旧位置。跨窗口日程已变化时，刷新本地投影并提示重试；服务器拒绝或实际排期偏离本地预测时，取得完整恢复数据后恢复排期并提示用户，较新的删除及普通未同步修改继续受保护。普通 CRUD 未解决写入仍使用原有同步保护。自动验证和真实客户端验收分别记录于 PC 模块。

### 2026-10-29 Chat 可视化教学（设计已确认；实现基础部分完成）

PC Chat 按时间线穿插模型过渡文字、真实工具胶囊、教学正文和组件。组件收到 `block.started` 时先显示 loading 外框；随后每个完整合法 `block.item` 到达就追加题干或选项行，不等待整个 block。单/多选题在题干、至少两个唯一选项和 `:::` 闭合后进入 READY；reference 可省略，存在时仅由服务端保留给后续 LLM。READY 后提交卡片答案会将原题和用户答案关联并交给下一轮 LLM；程序只校验提交形状和选项归属，不判分。INVALID 卡保留此前有效的题干/选项并禁用提交。题卡完成后结束本轮展示，用户可继续在输入框提问，也可稍后提交历史题卡。同会话已有执行时禁止发送/提交并保留草稿，停止确认后由用户发送。JSON 修复只接受完整行上的尾随逗号，安全诊断不包含原文；其它无效 JSON 不补造内容。

Compare 新结构（后端协议候选，前端待实现）：每个比较维度是一个 item `{title,entries:[{label,text},...]}`，至少两条 entry；按“维度标题 → 每个方案的 label/text 纵向列表”渲染。不要按 item 奇偶生成 A/B 横向行。相同 item shape 需由 projector/type/renderer 应用于流式 `block.item.row`、结束 `block.completed.part` 及历史 `MessageView.parts`。部署新后端后，旧前端不识别 `entries` 会丢失 compare 内容；旧 description-only 历史数据保留，但新 renderer 不提供兼容转换。字段示例及准确 SSE/history shape 见 [Chat Runtime API](../contracts/chat-runtime-api.md)。

### 2026-10-15 PC Overview 离线刷新失败与重试边界

- 仅静默 Subject/LOCAL 自动冲突解析按用户、设备、Subject 和 revision 合并进行中的同一解析；guard 在运行时初始化及缓存刷新前登记。FILE scope 与显式 LOCAL/REMOTE choice 保持原解析调用，不由此 guard 串行化。
- 连接失败保留已有本机 Overview 和冲突状态，不立即自行重拉；当前解析结束后，网络恢复触发的既有同步路径或用户明确的后续操作仍可重试。404 继续表示该 scope 暂无远端结果；鉴权、版本与数据完整性错误保持现有处理。生产 resolver 只在成功 resolve 后刷新尾部缓存；自动回归的失败尾部刷新是受控回调，不是生产失败分支行为。
- 登录账号、学科、文件修订或页面生命周期变化后，旧解析不继续操作新上下文。自动回归不替代真实断网恢复和桌面 GUI 验收。

### 2026-09-26 注销账户密码确认交互

注销确认提示本机会退出登录并保留本地业务数据，服务端会停用账户并后台清理云端数据。注销 API 返回 202 后清除本地会话并跳转登录页。注销或改密时，确认密码不匹配返回 `UNAUTHENTICATED` 与 `Invalid credentials`，留在个人空间显示接口错误。Bearer token 无效返回 `Authentication is required` 时走全局续期流程。改密成功后，当前设备自动续期并刷新设备列表，其他设备重新登录。

设备管理按稳定设备标识显示当前设备。撤销其他设备后，提示该设备无法续期，已有访问权限会在 access token 到期后失效。

## 设计目标

三端共享“极简禅意（Zen Minimalist）”语言，同时根据设备职责采用不同信息密度：

| 端 | 主要场景 | 设计重点 |
| --- | --- | --- |
| PC | 桌面学习工作台、学科与资产编排、时间线 | 高信息密度、多栏、鼠标键盘、文件预览、拖拽 |
| Mobile | 快速捕获、专注、复习、随身 AI、统计 | 单手操作、短路径、底部导航、弱网反馈 |
| Tablet | 完整学习、资料阅读、学习复习、AI 伴读与本地自由画布 | 触控、手写、可调整分屏与学习上下文保持 |

设计文档定义目标行为，不负责维护构建或验收状态；状态见 [当前状态](../current/Status.md)。

### 表面与圆角

- 页面背景使用禅白或暖灰白，不使用纯白大面积强对比。
- 主卡片采用 `16px` 左右圆角、发丝边框和极轻阴影。
- 模态弹窗（Modal / Dialog）采用温润大圆角 `20px`（`--radius-xl`）卡片与无缝一体化设计，彻底取消头部与底部的 1px 硬线条分割，依靠充裕留白划分层级；宽度体系遵循透气的梯度（`sm: 420px`, `md: 520px`, `lg: 680px`, `xl: 840px`）；内边距统一为头部 `24px 28px 12px`、内容区 `8px 28px 18px`、底部 `12px 28px 24px`。
- 模态弹窗材质与物理动效：遮罩使用 `backdrop-filter: blur(14px) saturate(180%)` 深层环境漫散，弹窗卡片内置发丝级内高光（`inset 0 1px 0 rgba(255, 255, 255, 0.7)` / 暗色 `inset 0 1px 0 rgba(255, 255, 255, 0.08)`）配合双层立体微晶柔光扩散阴影；进出场搭载阻尼弹簧动效（`scale(0.96) translateY(12px) -> scale(1) translateY(0)`，曲线 `cubic-bezier(0.16, 1, 0.3, 1)`）；关闭按钮集成 Tabler 矢量 `<IconX>`，支持悬停 90° 旋转与 0.92 触击回弹；表单输入控件聚焦时带有 `3.5px` 扩散式 Sage 柔光外环；知识块详情弹窗与新建任务弹窗（包含学科胶囊芯片、整半小时磁吸滑轨及截止日期胶囊）全面对齐该套微交互标准。
- 模态操作按钮统一采用全圆角 Zen 胶囊（`border-radius: 9999px`，高度 36px，主操作为统一的 `Primary Gradient` 禅绿渐变 `linear-gradient(135deg, #8E9F70 0%, #768758 100%)`，带 1.5px 微浮雕与 `scale(0.975)` 触觉阻尼，次操作为半透明微晶底板配发丝边框，危险操作为温润陶土红）；表单输入控件统一采用 `10px` 舒适圆角。
- 胶囊按钮和筛选器可使用全圆角，但长正文容器不得滥用胶囊形态。
- 侧栏、搜索、弹层可使用 `backdrop-filter: blur(20px)`，必须提供不支持毛玻璃时的实色后备。
- 阴影透明度控制在 `0.02–0.06`，禁止厚重悬浮阴影。首页三栏等大容器采用分层微阴影增强底部立体沉降感（如 `0 10px 24px -4px rgba(0,0,0,0.05), 0 2px 6px -1px rgba(0,0,0,0.03)`）。学科空间大厅（`SubjectHall`）与学科工作区（`SubjectWorkspace`）统一采用 `18px`–`20px` 现代圆角、透绿微晶边框与双层自然漫散光影；学科空间卡片悬停轻柔抬升 3.5px 并漫射透绿微光，内置掌握度细轨与数值微标；新建学科空间采用高阶微晶虚线磁吸卡片，加号悬停支持 90° 旋转放大；Tier 1 纵向导航条采用嵌入式胶囊激活态并移除生硬硬边线，材料抽屉项采用柔和滑入微动效。

### 排版

- PC 普通 UI 文本统一使用 `var(--font-family-base)`（DM Sans 优先，系统无衬线回退），页面组件不得再声明独立的 Inter、Outfit、Plus Jakarta Sans 等字体。
- 代码、知识图谱节点等确需等宽的内容统一使用 `var(--font-family-mono)`（Fira Code 优先，系统等宽字体回退）。
- PC 根字号固定为 `16px`；语义字号使用 `caption`（12px）、`body-sm`（13px）、`label`（14px）、`body`（16px）、`body-lg`（18px）、`title-sm`（20px）、`title`（24px）和 `title-lg`（30px），番茄钟等大数字使用 `display-sm`（48px）或 `display`（72px）。
- 标题字重 `700–800`，字距轻微收紧。
- 正文行高 `1.5–1.7`；手机正文不得因追求精致而低于可读尺寸。
- 次要信息只能降低对比，不能依靠过小字号隐藏。

### 动效

| 场景 | 时长 | 曲线 |
| --- | --- | --- |
| hover / focus | `150ms` | `cubic-bezier(0.4, 0, 0.2, 1)` |
| 颜色和普通面板切换 | `250ms` | `cubic-bezier(0.4, 0, 0.2, 1)` |

- 尊重系统减少动态效果设置。

## 通用交互状态

每个数据页面必须设计：

- 首次加载骨架或进度，不出现无解释空白。
- 空状态说明“为什么为空”和下一步操作。
- 请求失败展示用户可理解的原因、重试和安全退路。
- 保存中、已保存、同步中、离线、冲突和失败状态可区分。
- 删除等危险操作明确影响和可恢复性。
- AI 长任务展示输入上下文、处理状态、失败和重新执行入口。

## 导航与跨端原则

- 同一端内部导航稳定，禁止因窗口尺寸变化在 Mobile 与 Tablet 路由间自动反复跳转。
- `pages/launch/index` 只负责首次设备分流；进入某一端后保持该端导航体系。
- 微信小程序固定进入手机体验，不注册 Tablet 页面。
- 登录失效回到当前端登录页：手机 `/pages/mobile/login/index`，平板 `/pages/tablet/login/index`。
- PC `/login` 使用独立公共布局，不显示认证侧栏/头部；受保护路由仅在完整 user+token 会话下显示认证壳，未登录或会话不完整时返回 `/login`，避免认证初始化请求异常造成白屏。

### SubjectWorkspace

- 本地删除当前文件成功后，阅读区立即打开同学科列表中第一份剩余文件。没有剩余文件时回到学科总览。删除期间已改选其他文件或切换学科时，保留用户当前的选择。后台清理和缓存刷新不阻塞切换，也不改变已完成删除的反馈。本机草稿删除标记写入失败时提示重试。

- 目标是“选择资料或知识 → 在主区阅读/编辑 → 在辅助栏查看关系、总结或任务”。
- 知识块的“来源”必须显示关联 Source 的可读 `title`（对文件资料即原文件名），知识块学科标签必须显示关联 Subject 的可读 `name`；不得把 `sourceId`/`subjectId`/UUID 当成名称展示，关联投影暂缺时分别显示中性占位。ID 仅用于筛选、关联和写回。
- 学科图标需在大厅、工作区、首页、时间线和全局功能侧栏保持一致；新建学科使用语义键对应的线条图标，空值或未知语义键使用统一书本线条图标回退。Subject 不提供独立颜色；创建时不提供主题色选择，所有学科卡片、图标、选择态以及由学科触发的新知识块/任务统一使用 Sage Green `#7D9372`。Task 不读取持久化颜色字段，KnowledgeBlock 的独立 `colorOverride` 保留。
- 多栏应允许聚焦主内容；辅助栏关闭后释放空间，而不是留下空白占位。
- 文件预览统一由 `FilePreview` 承载加载、失败、下载和不支持状态；当前 PC 先用自托管 File Viewer 覆盖 PDF、DOC/DOCX、PPT/PPTX、图片和文本，Excel/未知格式在上传前拦截。上传入口与解析器能力保持一致，仅接受 PDF、DOC、DOCX、PPT、PPTX；图片和文本仍可预览但不允许创建 upload intent，`canPreviewFile()` 不再依赖 `allowedForUpload`，并以可操作的支持格式提示反馈。预览保持一个统一面板：学科页现有文件名顶栏承载缩放与旋转控制，缩放按 `− / 倍率 / ＋` 排列并与重置按钮放在同款圆角组内，旋转按线条图标、角度、线条图标放在另一组同款圆角框内；页码/总页数和前后页导航在预览主体底部占用独立布局空间。上下栏以轻微投影与实体按钮建立层次，中间文档上下保留约 12–16px 安全留白；搜索、打印、下载、HTML 导出和主题切换不进入预览工具栏。学科文件列表行不显示装饰性文件类型图案，文件名从行内容区起始。宿主不叠加会遮白正文的渲染遮罩，File Viewer 自身负责内部加载状态；首次宽度适配只执行到用户第一次交互，避免缩放后被重新 fit 回原倍率。控制按钮不因 renderer 加载状态被禁用，动作仅在组件 ref 尚未建立时暂存，不以 `load-complete` 作为执行硬门禁；基础 `@file-viewer/vue3` 组件通过 `withFullViewerOptions` 使用 full preset，缩放调用公开的 `zoomIn`/`zoomOut`/`resetZoom`，PDF/图片旋转通过 `applyViewState` 执行，避免 full 包装组件运行时 ref 丢失方法；旧的图片内部旋转栏隐藏，不支持 renderer 视图旋转的 Office 类型才回退到外层旋转。每次签名 URL 下载只允许最新文件选择提交结果，较早的响应不替换当前 renderer 输入。倍率和旋转角度由 renderer 实际状态回传。真实 DOC/DOCX 排版或资源兼容性不足时，替换组件内部 renderer 为服务端转 PDF，不改变学科工作区交互契约。
- SubjectWorkspace 文件栏只展示真实 Source 文件，不生成或显示独立的 `· 总结.md` 虚拟文件。选中文件后直接显示 `FilePreview`；总览中的“总结”快捷入口在同一中栏显示本地 AI 总结，并可返回文件，不增加右侧总结栏。文件行的删除操作默认悬停显示、键盘 focus-visible 时保持可见，并在确认后执行 Source 软删除；本地仍有 `SOURCE/CREATE` outbox 时排队有序删除，不直接请求尚未存在的远端 Source。墓碑和 DELETE outbox 成功写入后，当前文件列表、计数、AI 总览派生缓存和 Profile 中该文件的本地解析进度必须立刻消失；OCR/parser 取消、任务状态和加密 cache 清理在后台执行，不能拖慢界面或选中项回退。取消、未登录、版本冲突、资源不存在和服务端失败都必须有明确反馈。
- 知识图谱是关系探索辅助，不能成为访问知识块的唯一方式。
- AI 提炼必须显示当前学科和来源文件上下文。
- PC Tauri 学科工作区的 Chat 在首条成功准入时绑定当前学科、当前文件或手选资料。后续轮次继承该范围，工作区切换预览文件时继续显示已绑定的资料。用户可开启新会话重选范围，协议 1 的 `LEGACY` 会话可查看历史。文件未解析完成时发送入口弹出提示并导航个人中心查看进度。文件行仅显示无文字状态点，解析完成后消失，详细阶段、失败、重试和取消集中在 Profile 的文档解析中心；本地 upload complete 后仍须显示服务端 `VALIDATING/PARSING/INDEXING`，并且只有服务器 Source 变为 `READY` 后才能提问。Profile 对无本地 job 的 `AWAITING_CLIENT` 文件提供“开始本机处理”；该操作先同步并确认 Source 已在服务端建立，未确认时显示本地同步状态而不发起解析。单个历史文件失败不得阻断后续文件恢复。未挂载桌面 runner 时中心必须显示不可用原因，不能显示为无任务。可见 File Viewer 与离线 PDF/OCR 适配器必须解析同一精确 PDF.js 版本，避免共享 WebView worker 的 API 版本混用。预览中的原生选中文本可解释、追问或在确认标题/正文/标签后保存为当前学科/文件知识块。
- 登记本地参考文件弹层必须明确显示选择文件、名称和归档学科三个前置条件；确认按钮在缺少任一条件或上传中禁用。上传中保持极简克制视觉风格，展示简洁呼吸指示、当前阶段文本、平滑百分比与细腻绿意进度条（采用平滑插值算法，杜绝 10% 瞬间跳至 100% 的生硬突变，完成时留出短暂停顿反馈再平滑关闭），按钮展示微旋转与实时百分比；上传/登记失败以可理解通知反馈且保留弹层，允许用户修正后重试；直传完成后先把 Source 保存到本地、关闭弹层并立即刷新本地资料列表，后续同步不阻塞当前操作。工作区侧栏材料抽屉提供极简内嵌导入进度条，且文件列表行除状态圆点外，为非就绪文件提供小巧的状态标签（如 OCR 识别页码或解析中状态），便于用户即时感知导入解析进度；知识总览中的大纲卡片与学科总览卡片不再展示侵入性的“本机总览尚未同步”警告条，避免技术性同步重试干扰用户阅读总览。浏览器直传使用服务端返回的可达预签名地址，不把容器内部 hostname 暴露给用户。

### Asset 与 Timeline

- Timeline 日视图和周视图任务卡片的 × 显示「移回待办」提示，点击直接取消排期并保留任务；完成任务禁用该按钮，真正的删除操作保留在资料管理任务详情。
- Asset 明确区分待上传、上传中、处理中、完成和失败。资产树首屏优先展示本地 Subject、Source、KnowledgeBlock 与 Task 投影；单项本地读取或云端刷新失败时保留可用的本地树并结束 loading，不以永久转圈代替降级。云端数据由各 Store 写回本地后，资产树自动重建而不重新显示 loading。真实 Source 文件预览统一由 `FilePreview` 的 bare 模式承载，资产树将 Source `id`、`assetId`、`name` 与 `fileType` 传入该组件；首页不再提供冗余 PDF 伴读入口。
- Asset 关系星图以真实 Subject、Source、KnowledgeBlock 关系为依据，画布使用 Sage 绿学科节点、蓝灰文件节点与宣纸底色。关系使用对称节点互斥、按边类型设目标长度的弹簧吸引、弱重力与速度阻尼，初始坐标由稳定 ID 决定，初始模拟在收敛或 180 帧上限后停止。同范围刷新保留现存节点坐标与镜头，切换全局/学科范围时重新适配。Source 连接所属 Subject；KnowledgeBlock 的 `sourceFileId` 指向同学科现存 Source 时连接该文件，否则连接所属 Subject。鼠标、触控与触控笔均可拖动画布平移或拖动任意节点；节点拖动期间被拖节点保持在指针位置，关联邻居实时响应弹簧力，每段响应最多 36 帧并在收敛时提前停止；释放后最多 30 帧低强度松弛，使图谱轻微回弹并稳定。拖动/取消手势不触发节点选择，点击文件节点后在中栏打开该 Source 的 `FilePreview`，点击知识块节点后在中栏打开对应知识块编辑器；Home 继续触发 `open-block-detail`。图谱是关系探索辅助，知识块仍可从资产树直接访问。
- 资产库的“全部任务”与学科任务目录展示当前用户的真实 Task Store 数据，不显示固定演示任务；任务按 `未排期`、`未完成`、`已完成` 并列分组，已完成判断优先于未排期判断，组内按截止时间排布。任务编辑使用 30 分钟步进的预计用时选择，不再显示认知负荷按钮，并通过显式保存写回任务详情。列表刷新保留当前任务未保存的编辑，切换条目或删除任务时清理草稿。任务详情顶部提供“删除任务”，确认后从列表移除，已完成的未排期任务也可删除。时间轴导入入口通过 `/asset?focus=unassigned-tasks` 聚焦未排期任务。
- Timeline 拖拽必须有落点反馈、冲突提示和键盘/表单替代操作；原生拖拽状态必须含任务 ID，已排期任务还必须含原槽位。日视图固定呈现 08:00–22:30 的所有 30 个半小时刻度行，刻度行高度固定（80px+4px gap），不随任务存在而被压缩或隐藏；任务卡片按时长跨越网格，通过绝对定位层在视觉上向下跨越对应数量的半小时槽位，左侧时间标尺所有半小时刻度完整可见。普通空白时间槽执行原有插入顺延；任务卡片主体将被拖任务接到目标结束后的首个半小时槽，若与后续任务冲突则拒绝，其他任务保持原位。失败时保留完整原排期。仅卡片最顶部文字标题栏（`.task-header`，收敛为 `fit-content` 且文字子节点设为 `pointer-events: none` 阻断误清除）是双任务交换落点，并通过独立 drop 阻止事件冒泡；离开顶部文字区域的卡片主体及空白处均作为插入落点，不触发交换；待排期任务拖到该栏时给出可理解错误。拖回待办仅以任务 ID 取消排期。
- 插入请求包含源任务版本与 Timeline 当天 08:00–22:30 的时间窗口；服务端在单事务内验证版本、完成/取消状态、窗口边界与最终区间冲突，并返回实际变化的 Task。客户端保留源任务或受影响日的未解决本地同步状态围栏；收到响应后原子合并仍有效的成员，跳过旧版本和会清除墓碑的活动响应，再从当前 Repository 重建投影并触发 read sync。服务端已提交但缓存异常时仍读取本地投影并提示刷新，不直接用迟到响应替换页面。
- 卡片主体的已排期任务移动走严格放置，普通时间槽仍走插入顺延，两者均不调用 `schedule-swaps`；`.task-header` 的已排期任务交换继续调用服务端原子交换。排期移入过去时段、顺延越过当天窗口、或需要移动已完成固定任务时必须拒绝并保留原状态。
- Timeline 与 Dashboard 首屏优先呈现当前用户/`serverDeviceId` 范围内的本地任务投影，远端刷新不得阻塞已有任务显示；读取或刷新失败时保留已显示数据。Dashboard 切日更新内存选中日并重建槽位；Timeline 切日保留现有本地加载，但不得清空已显示任务。
- Timeline 的按槽排期和同日改期以操作发起时的具体本地日期为落点；等待写队列期间切日，已发起操作仍保存到原日期。已有排期的来源以完整日期核对，同日正常改期不提示来源变化。周视图已有活动排期任务可拖到另一日期列，从 08:00 起寻找同时满足过去时间、完整时长冲突和截止约束的首个半小时槽；无合法槽位时保留原排期。取消排期等待同步期间也可以重新拖入周视图日列，客户端立即显示选中的空槽，排期命令在取消之后同步。返回 Timeline 时从共享选中日期恢复标题和选中态，与任务槽位保持同一日期，包括下周。
- Timeline drop 松手时先复制拖拽任务数据并同步清除源卡片和落点高亮，再执行异步本地排期；拖到任务自身主体的 no-op 分支也清除拖拽状态。按槽插入和标题栏换位在本地原子提交完成后即释放排期写队列，远端同步由后台调度；本地失败即时提示，后台业务拒绝仍由排期同步错误通知提示。
- 五种拖放共用 Task Store 排期计算，日视图落点预览也使用该计算。LocalRepository 在单事务中保存受影响 Task 和排期命令，在线和离线共用本地提交路径。周视图拖到同一天保留原位，跨天使用 `SCHEDULE_INSERTION` 的严格模式，仅放置所拖任务。已有普通创建或更新在队列中的任务，在排期命令队列清空后沿用单任务更新链。拖回待办使用 `SCHEDULE_UNSCHEDULE`。传输失败时保留本地投影和 mutation ID，连接恢复后由 Sync 重放。服务端拒绝或版本冲突时在本地恢复完成后立即刷新页面并提示，随后再进行增量下拉。命令未结算时，pull 和 snapshot 继续保护其成员任务。实现细节见 [PC 模块](../modules/FrontendPC.md#2026-10-12-timeline-离线排期命令)。
- 取消拖动清除源卡和落点高亮。新建任务保存期间禁用重复提交，保存失败保留已填写内容。删除失败通过现有错误提示反馈。「已完成任务预计用时」合计已完成任务填写的预计时长。
- 日视图刻度行之间的 4 像素留白属于上一行的拖放范围。卡片主体的计算落点与源任务当前位置相同时，落点提示显示「已在目标时段」。
- 日视图和周视图的排期区域禁用文字选取，任务卡继续使用原有拖放规则，编辑表单支持正常文字选取。
- 所有 PC 排期写入按半开区间 `[scheduledAt, scheduledAt + durationMinutes)` 检查冲突；任务可在前一任务结束的同一时刻开始。取消任务不占用区间，已完成但保留排期的任务继续占用区间。按天排期寻找无冲突槽位；头部双任务换位必须在提交前同时验证双方新区间与其它排期及彼此不重叠。
- 新建或调整任务时间时，有截止时间的任务必须完整结束于截止时刻或之前；空时长按 30 分钟，无截止不限制。截止 `dueAt` 必须是带时区的真实时间戳；纯日期只在用户输入时转换为当地日末，读取旧数据时不将纯日期兼容解释为日末，非空无效/无时区截止值拒绝新排期。按天排期只选同时满足冲突与截止的槽位；拖放、插入顺延及换位检查每个新安排，任一超限保留整组原数据并提示任务结束时间超过截止时间，不发起写入。服务端再次校验远端最新数据。历史越界排期的非时间编辑和自动完成不因此被阻断。
- 排期修改与任务状态修改不得产生互相覆盖的无提示保存；完成任务不自动清除排期，移出排期必须是显式操作。Store 在启动和每分钟检查到期状态：有 `scheduledAt` 的任务在 `scheduledAt + durationMinutes` 结束时刻到达后自动完成并保留排期；无 `scheduledAt` 的 TODO/IN_PROGRESS 活动任务在有效 `dueAt <= now` 时自动完成并保留用户设置的截止时间，已完成/取消及空或无效截止时间不重复写入；TASK 投影刷新也触发检查，应用关闭期间到期在下次启动补处理。Timeline 待安排卡片与待办列表继续显示 DDL 提醒徽章。所有无排期的未完成活跃任务均可进入待安排队列并支持拖拽排期。拖放、按天排期与换位必须在目标 `scheduledAt` 早于当前时刻时拒绝，保留原位置且不发 API 或离线 mutation，并通过既有错误反馈显示原因。

- SQLite 快照重置在一个事务中读取 pending mutations、保护其资源及排期成员并替换远端快照；浏览器 localStorage 的 LocalRepository 状态改写要求 Web Locks API，并通过同源锁串行化；缺少该 API 时写入失败并返回 `LOCAL_STORAGE_LOCK_UNAVAILABLE`。Tauri SQLite 不受浏览器锁 API 限制。排期命令在同一 Sync cycle 遭拒绝时按 mutation ID 逐条提示，返回当前任务数组并完成原子恢复；若回执缺少本地受影响任务，客户端须先成功取得包含全部成员的完整快照再结束命令，快照失败或不完整则释放命令等待幂等重试。

### Pomodoro

- 任务选择列表和当前任务的排期时间统一显示具体日期与时刻，例如「11月16日 08:00」；跨年补全年份。

- PC 学科工作区的材料列表文件项负责选择并默认打开原文件；总览列表同时直接展示每个文件的大纲和总结快捷入口。

## 可访问性与输入

- 所有图标按钮提供可读标签。
- 键盘焦点顺序与视觉顺序一致，focus 状态不可移除。
- 颜色不是唯一状态信号；图表提供文字摘要或数据值。
- 拖拽、手势和 hover 操作提供点击、键盘或表单替代。
- 弹窗打开后焦点进入，关闭后返回触发元素。
- 手写和双指缩放只在支持设备上启用，并提供误触防护。

## 页面级验收清单

每个页面至少检查：

1. 路由入口与返回路径正确。
2. 未登录、token 过期和退出行为符合当前端。
3. loading、empty、error、offline、saving、synced 状态可识别。
4. 主要任务不需要依赖归档中的旧入口。
5. 小屏、常规宽度和目标大屏下无关键内容裁切。
6. 键盘、鼠标、触控和系统安全区符合目标平台。
7. 动效不造成首次点击闪回、白屏或布局跳动。
8. 数据来源、用户归属和同步状态清楚。
9. AI 输出、上传与解析失败可重试。
10. 构建通过与人工交互验收分别记录。

## PC 文档处理与 OCR 诊断

- 文档处理按真实页码推进：每页 OCR 前写入 `OCR_RUNNING` 检查点，页结果保留 `pageNumber/totalPages`、图片字节数、行数和耗时；空页不终止后续页，下一页继续处理并按有序 block ordinal 输出。
- 如果整份文档所有页归一化后都没有文字，任务以稳定错误码 `OCR_DOCUMENT_EMPTY` 失败；UI 展示页级进度和“未识别到文字”的可行动提示，不把空页误报为成功，也不伪造页数。
- 诊断是有界、可复制的 allowlist 摘要：仅含页码、总页数、图片大小、行数、耗时、结果和安全错误代码/说明。复制到剪贴板的文本不得包含 OCR 正文、完整图片路径、`Authorization`、签名 URL 或未 allowlist 的原始字段；复制失败须保留可见诊断而不阻塞任务。
- OCR 诊断只在本机处理边界可见，正文经现有加密 cache/package 边界上传；Rust/sidecar 日志同样只记录受限统计和截断 stderr，不记录识别文本或密钥。
- 断网暂停后点击继续时，带 payload receipt 的任务经 `PAUSED_NETWORK -> QUEUED -> UPLOADING` 直接恢复上传，不重跑 OCR、download 或 hash；无 receipt 的 `QUEUED` 任务仍回到解析流程。`NETWORK_OFFLINE` 对外保持稳定错误码，详情只显示 allowlist reason。
- 文档处理主密钥只保护本机加密 cache/package，不作为通用 E2EE 备份密钥。keyring 明确确认密钥缺失时，目标交互为自动创建新密钥、废弃旧 cache/receipt/续传进度，并从可取得的原始文件重新处理上传；原始文件不可取得时提示重新选择文件。不得用新密钥尝试解密旧 cache；访问被拒等 keyring 错误保留真实错误且不轮换密钥。该策略已确认但尚未实现，当前 runtime 仍会报 `DOCUMENT_ENCRYPTION_KEY_RECOVERY_REQUIRED`。
