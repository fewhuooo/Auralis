# Auralis 用户手册

更新时间：2026-11-15

文档状态：现行操作说明

权威范围：主要操作流程、平台差异和常见问题。实现与验收边界见[当前状态](../current/Status.md)，已知限制见[问题与复核](../current/IssuesAndReview.md)。

## 使用前说明

Auralis 将资料、知识、任务、专注和复习组织在学科工作区中。部分操作需要后端、对象存储和 AI 服务；桌面本地能力需要 PC Tauri。代码或构建已完成不代表真实设备与业务流程已验收，Mobile/Tablet 的页面和服务端接入也不等同于 PC。

## 登录与账号

PC 登录页支持用户名或邮箱加密码登录。注册需要邮箱验证码；忘记密码时使用邮箱验证码重置密码。登录失效后重新登录，再继续操作。

PC 的个人资料页提供账号资料、登录设备管理、密码修改和退出登录入口。修改密码后，其他设备需要重新登录。退出或进行本地数据重置前，先检查待同步操作；账户删除与本地重置是不同操作，按页面提示确认范围。

## 首页、学科与工作区

PC 首页展示今日安排与待办，可进入学科大厅、资产、时间线和个人资料。待办列表用于查看和处理任务；拖拽排期在时间线中操作。

1. 在学科大厅选择学科，进入工作区。
2. 选择资料，阅读内容并查看总览；按需要整理知识或创建任务。
3. 查看保存和同步状态，再切换设备继续。

Mobile 提供首页、时间线、专注等手机页面；Tablet 使用大屏布局和固定导航，工作区优先显示文件，并可打开总结栏。微信小程序只包含手机页面。

## 文件与资产

1. 在资产或学科工作区的上传入口选择文件。
2. 等待上传和资料处理状态更新。
3. 处理完成后阅读资料、生成总览或在聊天中引用资料。

FILE 资料的解析依赖同一账号下的 PC Tauri。Mobile 可上传和查看资料，但上传后仍可能等待 PC 处理；仅打开 PC 浏览器不等于启动桌面解析能力。上传失败时检查网络、文件限制和页面提示，修复原因后手动重试。

原始文件请自行保留。当前本地资产尚无完整备份、导出和恢复闭环。

## 总览与 AI 聊天

文件与学科总览包含重点大纲和连贯总结，均使用 Markdown，可分别生成、编辑和保存。生成失败或取消时保留上次有效结果。生成过程中如果修改了内容，应根据冲突提示选择保留的版本。

PC 的“自动生成概览”默认开启，符合条件的文件处理完成后会自动生成。关闭后跳过尚未派发的自动生成；已开始的生成继续处理，手动生成入口仍可使用。

聊天前确认当前学科和资料范围。新对话可在首条消息前选择资料；首条消息成功提交后，对话固定该范围，要更换范围请新建对话。聊天可结合资料回答并展示交互内容，AI 输出仍需人工判断。中断时按页面提供的停止、恢复或重试入口处理。

## 知识、任务与专注

知识块用于整理学习内容，可在工作区管理并查看关联。修改或删除后留意同步状态。

1. 新建任务，填写名称、学科、描述和预计时长等信息。
2. 在时间线安排时间；设置截止日期时，安排的整个时段应位于截止时刻之前。
3. 进入专注页面开始计时。
4. 结束后核对任务状态与统计。切换后台或锁屏后，也应检查计时状态。

## 复习与统计

PC 在学科工作区进入复习，查看待复习内容并提交结果；统计页面展示学习记录与趋势。图表为空时，先确认是否已有记录及是否完成同步。

手机和平板可从独立复习页打开到期卡片。平板也可在当前学科工作区点「复习」，查看该学科的到期卡片。翻面后上滑提交“认识”，下滑提交“不熟”，左滑跳过当前卡片，右滑取消手势。若保存中断，可在同一设备重新打开复习页并重试。

## 设置、同步与导出

PC 设置提供主题、字体、语言等偏好，以及同步和文件处理入口。关闭自动同步会暂停后台同步并保留待同步操作，仍可手动同步；恢复自动同步后再检查待同步状态。

PC 的 JSON 导出包含用户基本信息、知识块、任务及导出元数据，不包含原始文件，不能作为完整账户备份。进行重置或删除前，应分别保留需要的资料和数据。

AI 模型与服务配置、额度以及自动生成概览偏好位于个人资料页的 AI 设置中。配置发生问题时记录安全的错误提示，不在反馈中附带密钥。

## Tablet 手写

Tablet 手写笔记和文件批注入口默认关闭，端侧笔记不进入 Server 同步。恢复入口仍需笔输入、保存恢复和备份等专项验收，详见[手写计划](../current/RoadmapAndGates.md#tablet-手写保留边界)。不能将端侧笔记视为已同步或已备份资料。

## 常见问题

### 登录失效或接口提示未登录

重新登录后重试。如果仍失败，记录平台、时间和错误提示，并确认服务端可访问。

### 文件一直处理中

确认同一账号的 PC Tauri 已启动，检查网络及文件处理页面提示。如果持续失败，记录文件类型、处理状态和失败时间，交由维护人员排查。

### AI 没有回答

检查网络、当前模型配置和额度提示。保留输入，根据页面状态恢复或重试；持续失败时提供错误提示，不提交 API Key。

### 另一台设备没有更新

确认两端使用同一账号、网络可用且同步未暂停，执行手动同步并检查待同步或冲突提示。如果内容仍不一致，先保留现场，记录设备和操作顺序。

## 反馈信息

报告问题时提供平台、页面、操作步骤、期望、实际结果、时间、错误提示和网络状态。维护人员可结合[运维排障手册](../operations/Runbook.md)继续定位。不要提交真实密码、登录凭据或 API Key。
