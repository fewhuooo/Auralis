# PC 学科文件上传与预览设计

日期：2026-08-22

状态：已获用户确认，待实现

## 目标

收敛学科页的文件类型范围，先保证文件可预览，再分阶段接入解析；对不在支持范围内的文件在上传前直接拦截，避免创建无效的上传意图。

## 已确认的产品规则

- 学科页首期允许上传：PDF、DOC、DOCX、PNG、JPG/JPEG、WEBP、GIF、TXT、MD、JSON、XML、CSV。
- XLS、XLSX 直接禁止上传。用户选择或拖拽文件时立即提示，不请求后端上传意图，也不创建资产记录。
- 其他未知、可执行、压缩包、音视频等格式同样在前端拦截；后端再次校验扩展名和 MIME，不能只依赖前端。
- PDF、图片和纯文本类文件直接预览；CSV 按纯文本预览。
- DOC、DOCX 允许上传，但不在浏览器中直接解析 Office 二进制格式；预览阶段转换为 PDF 后复用 PDF 预览器，解析能力后续单独接入。
- PPT、PPTX 暂保持现有上传兼容行为，但不纳入本阶段预览和解析范围；若后续无法提供可靠预览，再单独收紧为禁止上传。

## 设计

### 1. 统一文件能力注册表

PC 新增单一文件能力注册表，以扩展名和 MIME 为输入，输出 `allowedForUpload`、`previewMode`、展示图标、拒绝原因和后续解析能力。上传选择器、拖拽区域、文件列表和预览入口全部复用该注册表，禁止在页面内继续散落扩展名判断。

首期预览模式：

| 类型 | 上传 | 预览 | 解析 |
| --- | --- | --- | --- |
| PDF | 允许 | 原生 PDF 预览 | 后续接入 |
| DOC/DOCX | 允许 | 服务端转 PDF | 后续接入 |
| PNG/JPG/JPEG/WEBP/GIF | 允许 | 图片预览 | 不解析 |
| TXT/MD/JSON/XML/CSV | 允许 | 安全文本预览 | 后续接入 |
| XLS/XLSX | 禁止 | 无 | 无 |
| PPT/PPTX | 保持兼容 | 本阶段不预览 | 本阶段不解析 |
| 其他格式 | 禁止 | 无 | 无 |

### 2. 上传前后双层拦截

- 前端在 `input`、拖拽和粘贴入口统一执行校验；不合格文件只显示错误提示，不调用 `POST /api/assets/upload-intents`。
- 后端上传意图接口复核扩展名、声明 MIME 和文件大小，拒绝不在白名单中的文件并记录结构化日志。
- 前端错误提示区分“格式不支持”“Excel 暂不支持上传”和“文件过大”，不把网络错误伪装成格式错误。

### 3. 预览流程

- 已完成上传的 PDF、图片和文本文件使用受权限保护的下载 URL，在学科页内打开对应预览器。
- DOC/DOCX 由后端在隔离临时目录中转换成 PDF；转换失败时保留下载入口并给出可读错误，不自动触发 AI 解析。
- 预览器限制资源来源为当前用户可访问的资产，禁止把文件 URL 交给第三方在线预览服务。

### 4. 分阶段解析

本阶段只完成能力判断、上传拦截和预览状态；不把“可上传”视为“已完成解析”。后续阶段分别实现 DOC/DOCX 文本提取和 PDF/文本入库，并沿用同一能力注册表。

## 错误和空状态

- 拖入 XLS/XLSX 时显示“暂不支持 Excel 文件”，文件不会出现在待上传列表。
- 拖入未知格式时显示“暂不支持此文件类型”，并提示当前支持范围。
- DOC/DOCX 转换中显示处理中状态；转换失败显示下载回退入口。
- 学科页没有可预览文件时显示引导，不注入演示文件。

## 测试与验收

- 前端单元测试覆盖扩展名/MIME 映射、XLS/XLSX 拦截、未知格式拦截和预览模式。
- 前端接口契约测试确认被拦截文件不会请求上传意图。
- 后端测试覆盖白名单、拒绝响应、大小限制和结构化拒绝日志。
- 人工验收 PDF、DOCX、PNG、TXT、CSV 可按预期预览；XLS/XLSX 在选择和拖拽两种入口都无法上传；PPT/PPTX 行为符合兼容策略。

## 非目标

- 本阶段不实现 Excel 预览或解析。
- 本阶段不实现 PPT/PPTX 预览或解析。
- 不引入第三方在线文档预览服务。
